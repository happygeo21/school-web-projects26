③ e-GIS 결합용 결과

파일을 넣으면 252개 기준의 결과표가 자동으로 만들어집니다.
최종 권장: code ↔ join_code
레이어 키 = code · 속성 키 = join_code
e-GIS의 Google Sheets 가져오기는 첫 번째 열을 제외하고, 그 다음 열을 _1처럼 바꾸는 동작이 반복 확인되었습니다. 그래서 이제 Sheets용 복사본 앞에 보호용 열 2개를 두고 join_code를 세 번째 열에 배치합니다. 기존 시트에서는 _1 값이 51190·51770처럼 5자리 시군구 코드라면 임시로 _1을 선택해도 됩니다.
저장
결과는 기준표 252행을 그대로 유지합니다. Google Sheets용 복사는 row_id · guard · join_code · name · sido_name · 통계열 순서로 복사합니다. 앞의 두 열은 e-GIS 가져오기 과정에서 사라지거나 _1로 바뀌어도 괜찮은 보호용 열입니다. 실제 결합에는 세 번째 열 join_code를 사용하세요.
e-GIS에서 이렇게 선택
1 대한민국 시군구(252개) 레이어 불러오기
2 테이블 결합 실행
3 레이어 키(지도) = code
4 속성 키(통계표) = join_code
5 row_id·guard·_1은 보호용이므로 무시
6 2020·2021·2022…는 결합키로 선택하지 않기
7 결합 후 원하는 연도 통계로 단계구분도 작성
