지역 선택

1단계 · 무엇을 비교할까요?

시도 값은 시도 지도에, 시군구 값은 같은 시군구 지도에 연결해요. 17개·252개는 2025년 지도 기준이며 모든 통계표의 필수 행 수가 아닙니다.

상위 시 합계만 있는 시군 자료는 일반구 경계와 다를 수 있어요. 같은 시군 경계를 확인하기 전에는 일반구에 값을 나누거나 복제하지 않습니다.

2단계 · 자료를 찾거나 넣으세요

아래 검색은 공식 KOSIS로 연결됩니다. 실제 통계는 표의 지역·연도·단위를 확인한 뒤 내려받으세요.

KOSIS e-지방지표 통계표 · KOSIS 통계놀이터에서 지역 자료 찾기

전국17개를 볼 때는 시도 행만, 시군구를 볼 때는 시군구 행을 선택하세요. 예전 외국인·신혼부부·경지면적 원본은 현재 제공되지 않아 실제 검증이 안 된 추천 후보입니다.

총인구 공식 통계표 · 고령인구비율 공식 통계표

실제 예제 통계 파일은 아직 검증하지 못했습니다. 공식 표에서 시군구·지표 하나·시점 하나를 선택하고 Excel로 내려받으세요. 아래 연습자료는 합성입니다.

한 번에 한 연도·한 공간 단위로 비교하세요. 252개는 내장 지도 기준표의 지역 수이며 모든 통계표의 지역 수가 아닙니다.

2단계 · 엑셀 넣기

파일은 서버에 업로드하지 않습니다. 최대 20MB·100,000행·500열. 큰 자료는 필요한 지역과 지표만 내려받으세요.

연습자료는 기능을 익히는 합성 수치입니다. 실제 KOSIS 통계나 연구 결과로 사용하지 마세요.

아직 파일을 넣지 않았습니다.

3단계 · 지역과 통계값 확인

원본 파일과 미리보기는 지도 선택을 바꾸어도 보존됩니다. 추정이 틀리면 아래 열 선택과 원본 표를 먼저 확인하세요.

지역명은 ‘전라남도 화순군’처럼 입력하거나 시도 열을 따로 선택하세요. 같은 이름의 중구·고성군은 시도 정보가 필요합니다. KOSIS의 표마다 지역코드가 다릅니다. 코드 열을 선택 해제해도 원본 코드를 무시하지 않습니다. 화순군2024는 원본 통계표·전라남도·연도를 확인해야 연결합니다.

지도에 나타낼 통계 열을 선택하세요
헤더가 잘못 읽혔나요?

열 이름이 있는 첫 행과 헤더 줄 수를 선택하세요. 여러 줄 헤더와 병합 셀을 펼쳐 읽습니다. 지역명·코드가 통계 열로 선택되지 않았는지 확인하세요.

시군구 자료를 시도 값으로 집계할 때만 열기

시군구가 빠졌거나 중복되면 합계를 만들지 않아요. 비율을 단순 평균하지 않습니다.

3단계 · 변환과 점검 결과

파일을 넣고 변환하세요.

‘원본 값 대조표’에는 지역별 원본 행번호와 변환 전후 값을 기록합니다. 원본·결과가 일치해도 경계연도·분석범위와 실제 지도 결합은 따로 확인하세요.

집계 계산식·누락·원본 시도값 비교
CSV는 UTF-8 BOM 형식입니다. Excel에서는 ‘데이터 → 텍스트/CSV에서’로 열고 code·sido 열을 텍스트로 지정하세요. XLSX는 코드를 텍스트 셀로 저장합니다. 결합 중단 상태에서는 지도용 저장을 막습니다.
문제 행 수정
지역을 잘못 인식한 행은 기준 지역을 직접 선택하거나 제외하고 다시 검증하세요. 수치 오류·중복 연도·지표는 원본 파일을 고쳐 다시 넣어야 합니다.


4단계 · 지도 만들기


e-GIS에서 지도를 완성해요
아래 단계를 눌러 따라 해보세요. 실제 결합과 지도 결과는 e-GIS 화면에서 확인해요.
e-GIS 열기 ↗학생 시범 지도 2종 보기 ↗
    자료 단위를 확인하면 같은 단계의 경계를 추천해요.
    시도 지도는 2025년17개 기준(e-GIS 카탈로그 ~2026.06.30. 표기)입니다. 출처표기는 KOSTAT이며 e-GIS 배포원본은 확인했지만 원기관 원본과 독립 대조한 것은 아닙니다. 다른 연도·개편 경계는 다시 확인하세요.
    1. e-GIS 열기 → 통계와 같은 기준시점·공간 단위의 경계 레이어를 불러옵니다.
    2. 속성 테이블에서 실제 지역 코드 열의 이름과 값을 확인합니다. 이름이 code라고 가정하지 마세요.
    3. 레이어 → 테이블 결합에서 지도 쪽 키와 CSV 쪽 code를 각각 선택합니다. Google Sheets도 실제로 인식된 열 이름과 값을 확인합니다.
    4. 코드가 연결된 지역 수와 통계값이 있는 지역 수를 각각 기록하고, 화순군 등 표본 지역의 숫자가 원본과 같은지 확인합니다.
    5. 주제도 → 단계구분도에서 선택한 숫자 열로 지도를 만듭니다. 빈칸을 0으로 표현하지 마세요.
    내장 기준은 2026-10-30 확인한 e-GIS 공개 시군구 경계(2025년) 252개와 다섯 필드가 일치합니다. 지금 선택한 지도도 같은 경계인지 확인하세요. 실제 지도 결합·단계구분도 제작은 별도 검증이 필요합니다.
    탐구: 고령인구 ‘비율’이 높은 지역과 ‘인원수’가 많은 지역은 같을까요? 지도 제목·단위·출처·연도·분석 한계를 적어보세요.
