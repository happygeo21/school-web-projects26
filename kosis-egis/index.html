⑥ 저장하고 e-GIS에 올리기

먼저 변환을 완료하세요.
파일 저장

CSV는 가장 단순하고 안전한 결합용 형식입니다. XLSX는 eGIS_READY + README 시트로 저장합니다.

Google 스프레드시트로 보내기
  1. ‘표 전체 복사’ 클릭
  2. 새 Google Sheet A1에 붙여넣기
  3. 공유 → 링크가 있는 사용자 ‘뷰어’
  4. e-GIS → 데이터 불러오기 → 스프레드시트 탭 → 공유 링크 입력

복사용 TSV

e-GIS ‘데이터 불러오기’ 메뉴를 한눈에

이 변환기는 특히 속성 통계표 → 테이블 결합을 자동 정리하는 데 초점을 둡니다. 아래는 2026 e-GIS 연수자료의 메뉴 구조를 학생 눈높이로 재정리한 것입니다.

1. 내장 데이터
공간 데이터속성 데이터점 데이터래스터스프레드시트

시도·시군구·세계 국가, 인구·GRDP, 매장·의료시설, DEM 등을 바로 불러옵니다. Google Sheet 공유 링크도 같은 창의 스프레드시트 탭에서 가져올 수 있습니다.

2. 파일 가져오기

왼쪽 레이어 패널의 + 또는 브라우저 탭. GeoJSON .geojson/.json, Shapefile .zip/폴더, GeoPackage .gpkg, DEM .tif/.img.

3. 좌표 데이터 가져오기

.csv .txt .xlsx .xls에서 위도·경도 열을 지정해 점 레이어를 만듭니다. 좌표계는 값으로 자동 추측하고 필요하면 변경합니다.

4. 공공데이터

데이터 불러오기 → 공공데이터 탭에서 지역·검색어로 시설을 찾고, 미리보기 후 포인트 추가 / 격자 집계 / 히트맵 중 선택할 수 있습니다.

5. Geocoding

주소만 있는 표를 좌표로 바꾸는 길입니다. 주소 목록 → Geocoding → 결과를 가져온 뒤 좌표 데이터 가져오기로 지도에 올립니다.

6. 테이블 결합
메뉴 → 레이어 → 테이블 결합

CSV·엑셀 통계표를 공간 레이어에 붙입니다. 레이어 열과 표 열에서 키를 각각 지정하며, 결합 후 단계구분도·도형표현도·필드 계산기에 사용할 수 있습니다.

중요: e-GIS 화면이나 내장 레이어 이름은 업데이트될 수 있습니다. 결합 전에 대상 레이어의 속성 테이블에서 실제 키 값을 확인하는 습관이 가장 안전합니다.
