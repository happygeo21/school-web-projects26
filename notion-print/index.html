권장 Notion에서 인쇄할 본문 블록만 선택해 복사 → 이 파일에서 클립보드 붙여넣기 → 필요하면 글자·여백 조절 → 인쇄. 특정 Notion URL에 종속되지 않으며, 어떤 페이지든 반복해서 사용할 수 있습니다.

범용 Notion A4 Print Studio 사용법

  1. Notion에서 필요한 본문만 복사합니다. 페이지 안에서 블록들을 드래그 선택하거나, 블록 선택 상태에서 복사하세요.
  2. 이 HTML을 열고 클립보드 붙여넣기를 누르거나 편집 영역에서 Ctrl+V 합니다.
  3. 제목·목록·표·이미지는 가능한 범위에서 그대로 유지됩니다. 불필요한 부분은 여기서 직접 삭제·수정하세요.
  4. 자동 맞춤에서 목표 1~5쪽을 고르면 글자 크기·줄간격·여백을 단계적으로 줄여 해당 쪽수에 가깝게 맞춥니다.
  5. 원하는 위치에서 페이지 나눔을 누르면 그 지점부터 다음 A4에서 시작합니다.
  6. 이미지를 클릭하면 선택됩니다. 선택 이미지 삭제로 제거할 수 있고, 상단의 이미지 최대 폭으로 전체 이미지 크기를 조절할 수 있습니다.
  7. 완성 후 인쇄 → 용지 A4 → 배율 100% → 머리글/바닥글 끔 → 배경 그래픽 필요 시 켬으로 사용하면 됩니다.

중요: 이 정적 HTML은 Notion URL만 넣어서 페이지를 자동으로 가져오지는 않습니다. 브라우저의 보안(CORS)과 Notion 로그인/권한 때문에 임의의 Notion 페이지를 안정적으로 직접 읽을 수 없기 때문입니다. 대신 복사·붙여넣기 방식이라 공개/비공개 페이지 모두 사용할 수 있습니다.
