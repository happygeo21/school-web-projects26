# 에너지 결정사: 최애에서 드림팀으로

고2 「세계시민과 지리」 4단원, 50분 × 2차시. 기존 캐릭터·프로필·관심 선택을 탐구의 출발점으로 유지하고, 21문항을 핵심 개념 10문항(차시별 5개)으로 묶는다. 교과서 기반은 원본 student.html의 QUESTIONS·LMETA와 내장 교과서 p04–16이다. 이번 대화에서 별도 시범 HTML·수업안 첨부 파일은 확인되지 않아 GitHub 원본을 기준으로 구성했다.

## 학습 목표

- 자원의 유한성·편재성·가변성을 사례로 구별한다.
- 화석 연료의 이용·생산·소비 차이와 대표 국제 이동을 지도에서 설명한다.
- 재생 에너지의 입지와 한계를 비교하고, 공급 안정성과 탄소·비용·공정성을 함께 고려한 에너지 조합을 제안한다.

| 5–17분 (12분) | 캐릭터 스피드 데이트: 세 명 이상 프로필 비교 | 용도·분포·강점·약점 | 유한성·편재성·가변성 및 화석/재생 구분 |

## 2차시: 드림팀과 돌발 미션 (50분)

| 시간 | 활동 | 학생이 남길 결과 | 교사의 확인 |
|---|---|---|---|
| 0–5분 (5분) | 복습: 지도 경로와 에너지 안보 | 공급이 끊기면 생기는 문제 | 다변화·수요 관리 연결 |
| 5–20분 (15분) | 에너지 드림팀 스카우트: 캐릭터 세 명 선발 | 목표·역할·근거·약점·보완책 | 프로필·교과서로 필요한 개념을 먼저 확인 |
| 20–32분 (12분) | 돌발 상황 카드 한 개 해결 | 팀 유지/교체와 단기·장기 대응 | 대체 설비·시간·비용 제약까지 설명 |
| 32–45분 (13분) | 핵심 문항 6–10, 짝과 자기 수정 | 개인 응답 5개와 판단 근거 | 안보·입지·한계·상충 관계를 활동에 되돌려 적용 |
| 45–50분 (5분) | 공유: 짝 팀 검토, 최종 매칭과 저장 확인 | 반론 하나와 최종 조정 근거 | 학생 저장 상태와 교사 조회를 별도로 확인 |

학생·교사 v2 화면의 시간표와 동일한 순서다. 스카우트·돌발 활동은 프로필을 참고하는 탐구 활동으로 먼저 진행하고 문항은 뒤에서 개념을 점검한다. 최종 발표 문장은 “우리 팀은 …을 위해 …을 조합하되 …을 보완한다.”로 정리한다.
## 활동 설계

관심 선택은 탐색을 촉진하는 장치다. 많이 선택하는 학생에게 높은 점수를 주지 않는다. 드림팀은 기존 아홉 에너지 캐릭터 중 역할이 다른 세 명을 선택하며 비율 100%를 맞추는 가상도시 활동을 사용하지 않는다. 전기 공급, 수송 연료, 제철 원료의 용도를 혼동하지 않도록 목표와 역할을 먼저 쓰게 한다. 특정 전원을 반드시 넣거나 빼게 하지 않으며, 선정 근거와 한계를 평가한다.

돌발 카드는 수입 항로 차질, 흐리고 바람 약한 날 지속, 주민의 입지 이의 제기로 구성한다. 상황은 가정이며 현재 발생한 뉴스로 제시하지 않는다. 팀 유지도 근거가 있으면 가능하다. 화석 연료·원자력·재생 에너지를 한 문장의 선악 구도로 분류하지 않는다.

## 형성평가 10문항과 근거

기계 판독 가능한 본문·선택지·0부터 시작하는 정답·해설은 happygeo/lesson-content.json에 둔다.

선택형은 10점 형성평가로만 사용한다. 프로필 선호, 답안 수정 횟수, 완료 속도는 점수에 넣지 않는다. 정답을 맞힌 뒤에도 선택 근거를 짝에게 설명하게 한다. 10번은 여러 해법이 가능한 활동의 개방성을 유지하면서, “조건과 상충을 비교한다”는 판단 원칙을 묻는다.

## 활동 피드백 기준 (각 0–2, 총 8점)

- 개념 정확성: 0 근거 없음 / 1 일부 정확 / 2 자원·용도·입지 개념이 정확함.
- 지리적 근거: 0 지역 조건 없음 / 1 지도 또는 프로필 한 개 / 2 지도와 입지·소비 조건을 연결함.
- 보완 관계: 0 선호만 나열 / 1 약점만 언급 / 2 약점과 실제 보완책을 연결함.
- 돌발 대응: 0 상황과 무관 / 1 대응 한 개 / 2 단기·장기 대응과 한계를 설명함.

교사 화면은 1·2차시의 5문항 진행·정답 수, 총 10문항, 드림팀 세 명과 선정 이유, 돌발 대응을 중심으로 확인한다. 이전 3차시·21문항 기록은 신규 10문항 성적에 합산하지 않고 원본 기록으로 보존한다.

## 교차 검토와 사실 경계

세계지도 대표 경로와 지리적 설명은 지리 검증 담당의 교차 검토를 완료했다. 정답 인덱스 10개를 확인했고, 5번 석탄 사례를 실제 지도에 수록한 인도네시아→중국·인도로 일치시켰다. 원본의 석탄/석유 부문별 비중은 2020년 자료로 명시되어 있으나, 이번 10문항에서는 최신 통계처럼 오해할 수 있는 비율·생산 순위를 묻지 않는다. 원본 표현 “석탄의 국제 이동은 상대적으로 적음”은 지표·연도 없이 일반화하지 않는다. LNG와 수송관을 구분하고, 천연가스를 무탄소로 표현하지 않는다.


## 최종 통합 반영 · 2026-10-23 KST

첨부 시범 HTML·수업안·지도 PNG를 후속 대조했다. 첫 팀과 근거 보존, 최종 팀, 개인 3문장 보고서 및 TXT 내보내기를 추가했다. 문항은 참고안의 10개 핵심 개념에 맞추고 5+5로 유지했다. 지도는 21개 연결(석탄7·원유6·천연가스8), 운송수단 필터·전체보기·선택확대·지역명 전환으로 보완했다. 중복 라벨과 유럽 라벨 중첩을 해소했다. 루브릭은 개념 정확성·지리 근거·보완 관계·돌발 대응 각0~2점으로 통일했다. 교사 평균의 미응답 포함과 형성평가 성격을 표시했다. 최종 브라우저6개 및 콘텐츠/격리권한/공개경계7개 검증은 README와 테스트 스크립트 참조. 운영 Firebase·실제 Rules·기기간 동기화는 미확인으로 유지한다.
