# 독립 평가 문항·집계 검토

검토 범위: `happygeo/lesson-content.json`, `happygeo/two-lessons.js`, 학생·교사 v2 HTML, `docs/happygeo/lesson-plan.md`. 수업 설계 담당과 별도로 문항의 정답, 모호성, 범위, 채점 및 완주 조건을 검토했다. 외부 자료의 최신 교역량 검증은 지리 담당의 별도 검증 범위다.

## 문항 검토 결과

정답은 JSON의 `answerIndexBase: 0`과 일치한다. 학생 화면 채점은 `q[2]`와 비교하고 교사 정답 표시는 `q[2]+1`로 변환하여 일관된다. 차시마다 5문항, 총 10문항이다.

범위는 자원 3특성, 이용 변화, 화석 연료 용도와 국제 이동, 에너지 안보, 수력·풍력·태양광·지열·바이오, 에너지 조합을 포함한다. 원자력의 구체적 장단점은 독립 선택형 문항으로 평가하지 않으므로 프로필·팀 제안 피드백에서 다뤄야 한다. 모든 세부 개념을 10문항만으로 평가했다고 해석하지 않는다.

## 채점·완주·공정성

- 각 문항은 1점, 최종 선택 기준이다. 해설이 즉시 공개되고 재응답할 수 있으므로 형성평가에 적합하다. 최초 독립 수행 능력이나 총괄 성적의 증거로 사용하지 않는다.
- 관심 수, 테마 선택, 응답 속도, 수정 횟수는 점수에 반영되지 않는다. 특정 에너지 선호에 유불리가 없다.
- 완주는 정답 수가 아니라 10문항 응답, 서로 다른 팀원 3명, 팀 제안서·지도 메모·미션 대응의 작성 여부로 판정한다. 완주율은 학습 숙달도 또는 제안서 질을 뜻하지 않는다.
- 저장 기록은 신규 스키마만 집계하고 이전 21문항 기록을 합산하지 않는다. 차시별 문항 정답률은 해당 문항 응답자를 분모로 사용한다.
- 미션 난도는 같다고 입증되지 않았다. 상황 선택과 재추첨을 허용하므로 미션 수나 수행 속도에 점수를 부여하지 않고 동일 루브릭으로 근거를 피드백한다.

## 통합 담당에게 전달한 개선점

1. 교사 HTML의 피드백 항목(지리 근거·역할 보완·상황 대응·한계 성찰)과 수업안의 루브릭(개념 정확성·지리적 근거·보완 관계·돌발 대응)이 다르다. 같은 항목으로 통일해야 한다.
2. 교사 총점·차시 평균은 새 기록 보유자 전체를 분모로 하고 미응답은 0점으로 계산한다. 차시 참여 수도 동일한 전체 인원이다. 수업 도중 이를 오답 또는 낮은 숙달도로 오인하지 않도록 미응답 포함 평균임을 명시하고 차시 참여는 실제 응답자 수와 구분하는 것이 바람직하다.

위 두 항목은 통합 담당에게 전달했으며 이 검토에서는 애플리케이션 코드를 수정하지 않았다. 문항의 정답 오류나 복수 정답을 요구하는 차단 수준의 문제는 발견하지 못했다. 최종 통합 후 안내 문구 반영 여부는 통합 담당의 확인 대상이다.


## 최종 통합 반영 · 2026-10-23 KST

첨부 시범 HTML·수업안·지도 PNG를 후속 대조했다. 첫 팀과 근거 보존, 최종 팀, 개인 3문장 보고서 및 TXT 내보내기를 추가했다. 문항은 참고안의 10개 핵심 개념에 맞추고 5+5로 유지했다. 지도는 21개 연결(석탄7·원유6·천연가스8), 운송수단 필터·전체보기·선택확대·지역명 전환으로 보완했다. 중복 라벨과 유럽 라벨 중첩을 해소했다. 루브릭은 개념 정확성·지리 근거·보완 관계·돌발 대응 각0~2점으로 통일했다. 교사 평균의 미응답 포함과 형성평가 성격을 표시했다. 최종 브라우저6개 및 콘텐츠/격리권한/공개경계7개 검증은 README와 테스트 스크립트 참조. 운영 Firebase·실제 Rules·기기간 동기화는 미확인으로 유지한다.
