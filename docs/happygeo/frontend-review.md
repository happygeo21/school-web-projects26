# 프런트엔드·지리 교차 검토

검토일: 2026-10-23. 검토 대상: `two-lessons.js`, `energy-routes.json`, `energy-characters.json`, `previews/world-desktop.png`, `previews/world-mobile.png`. 코드 수정 없이 정적 로직과 저장된 화면을 검토했다. 직접 브라우저 클릭 테스트를 대신하는 기록은 아니다.

## 확인한 결과

- 8개 경로의 출발·도착 및 EIA 출처가 지도 선택 정보 카드에 연결된다. 기준연도·운송 수단·설명도 함께 표시한다. 경도·위도를 정거원통 투영에 맞춰 계산한다.
- 지도 경로는 클릭뿐 아니라 Enter/Space로 선택 가능하고, 별도 경로 버튼과 `aria-pressed` 상태를 제공한다. 모바일 전체 지도에서 작은 글자를 읽기 어렵더라도 버튼과 상세 카드로 같은 내용을 확인할 수 있다.
- `zoomRoute`는 선택 경로의 양 끝점을 포함한 영역으로 확대하고 세계 전체 보기로 복귀한다. 확대 상태에서 다른 경로/연료를 선택하면 새 선택에 맞춰 viewBox를 계산한다. 구현 확인이며 실제 모바일 조작 확인은 통합 테스트 담당 범위다.
- 문항의 인도네시아→중국·인도 석탄 예시가 지도 데이터와 일치한다. LNG선과 가스관의 구분도 유지된다. 미국→유럽 설명은 천연가스 전체가 아닌 LNG 공급이라고 한정한다.
- 캐릭터 설명은 석탄의 국제 교역, 생산·소비·수출 지표의 차이, 가스의 CO₂·메탄 누출, 원자력의 비재생성, 태양광·풍력의 변동성 및 보완 수단을 반영했다. 기존 ‘2020년 81.8%’를 새로운 일반 사실로 단정하지 않는다.

## 화면에서 확인한 개선 권고

- PC 천연가스 전체 지도에서 노르웨이·독일·유럽(EU·영국) 라벨이 중첩된다. 현재 `draw()`는 각 경로 양 끝에 같은 오프셋을 사용한다. 선택 경로만 라벨을 표시하거나 노르웨이·독일·유럽의 라벨 위치를 서로 다르게 조정하는 것이 좋다.
- 같은 좌표·같은 명칭의 출발 라벨이 경로 수만큼 중복 생성된다(카타르, 인도네시아, 사우디아라비아). 명칭+좌표로 중복을 제거하면 가독성이 좋아진다.
- 모바일 전체 지도는 공간 관계를 개괄하기에는 유용하지만 라벨 판독에는 작다. 경로 확대 버튼을 유지하고, 확대 후 선택 지점명과 화살표가 잘리는지 모바일 브라우저에서 확인한다.
- 곡선은 육지·해협을 실제로 우회하지 않는다. 지도 주변에 실제 항로·가스관 위치가 아닌 대표 교역 방향이라는 안내를 계속 표시해야 한다. 노르웨이→독일의 짧은 선도 실제 가스관 노선으로 해석하면 안 된다.

## 표현상 남는 한계

태양광의 ‘생산 비중이 높다’, 바이오의 미국·브라질 ‘생산 비중’은 통계 분모와 기준연도가 없어 정량 비교로 사용하지 않는다. 지열의 판 경계·화산 조건은 일반적인 전통 지열 발전 입지이며 모든 지열 기술의 필요조건은 아니다. 캐릭터 카드는 경향 설명이고 최신 국가별 순위 자료가 아니다.
