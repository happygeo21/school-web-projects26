## 1. 개발 완료 기능

기존 파일 읽기·UTF8/BOM/EUC-KR·XLS/XLSX 다중시트·수동 지역 지정·범위/연도/중복/결측 검사·CSV/XLSX 내보내기를 유지했습니다. 원본 행번호·원래코드·지도코드·지표·원본값·정리값·출력값·대조상태를 기록하는 원본값 대조표(CSV/JSON/XLSX)를 추가했습니다. 이것은 입력 파일의 변환 전후 점검이며 출처·실측값의 정확성을 인증하거나 잘못된 지리 매칭을 별도로 입증하는 검사는 아닙니다. 교사용 독립 비교도구는 원본 XLSX와 사용자가 실제 다운로드한 CSV를 다시 대조합니다.

설명/메타 시트 대신 자료 시트를 우선 선택하고 한 개의 명확한 원본연도는 자동 인식합니다. 잘못된 열·시트 선택은 미리보기와 오류 안내를 통해 수정해야 합니다. 실제 파일을 아직 받지 못한 상태에서 모든 KOSIS 형식을 정확히 자동 인식한다고 주장하지 않습니다.

## 2. 실제 KOSIS 통계3종

현재 실제 수치 파일은 0개 확보, 원본행수·성공지역수·값 불일치수는 미측정입니다. 앞선 자료조회 경로는 HTTP200의 서비스 차단 Notice를 반환했으며 이를 우회하지 않았습니다. 이번 공식 공개 검색은 HTTP200으로 성공했고 고용노동부 시군구 사업체 표의 메타데이터를 새로 확인했습니다. API secret은 없고 원격 브라우저 다운로드도 실행하지 않았습니다. 실제값을 합성값으로 대체하지 않습니다.

교사가 받을 파일은 **전남 시군·2024년·지표 하나**로 통일합니다.
