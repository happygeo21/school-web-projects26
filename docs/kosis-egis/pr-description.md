## 문제와 변경

기존 두 변환기의 결과가 달라질 수 있고 코드·이름 불일치와 중복 자료가 정상 값으로 남을 수 있었습니다. 학생 대표 URL `/kosis-egis/`와 대체 URL을 유지하면서 공통 엔진으로 통합하고, 전국·시도·표본 범위와 기준연도를 구분해 미매칭·중복·결측을 각각 보고합니다. 중복·충돌·수치 오류가 있으면 지도용 저장을 차단합니다.

학생 화면은 자료 찾기/파일 입력 → 자동 점검 → 변환 → 지도 제작의 흐름으로 바꾸고, 인코딩·다중시트·수동 지역 지정·CSV/XLSX 저장과 Web Worker 변환을 지원합니다. 교사용 Worker는 인증 service binding·rate limiter 없이는 차단하며 별도 배포가 필요합니다. legacy·Firebase·다른 수업 앱은 수정하지 않았습니다.

## 검증

- 엔진 테스트 18개, Worker 모의 테스트 4개, Chromium 시나리오 10개, 기존 회귀 테스트 3개 통과.
- 전국252·전남22 합성자료, 중복명·일반구·오류, UTF8/BOM/EUC-KR, XLS/XLSX 다중시트·병합, 다운로드 및 5만행 UI 응답 확인.
- 공개 산출물 빌드 및 allowlist·원본 바이트·로컬 참조 검사 통과.
- 실제 KOSIS·e-GIS·Pages 접근은 환경 네트워크 403으로 미검증. 공식 원본 레이어 미제공. 실제 수업 운영 최종 승인 보류, 배포·자동 병합 없음.
