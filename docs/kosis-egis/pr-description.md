# KOSIS–eGIS 공간 단위 선택과 안전한 집계

시도 통계가 시군구 값으로 복제되거나 상위 시 합계가 일반구에 중복 연결되는 해석 오류를 막습니다. 학생이 전국 시도·전국 시군구·특정 시도·자동 추천으로 시작하고, 원본 지역 단계 확인 후 같은 단계의 지도에 결합합니다. 17·252는 지도 기준 수이며 모든 통계표의 필수 행 수로 강제하지 않습니다.

- 기존 시군구 엔진·화순군 표별 교차표를 유지하고 별도 공간 단위 검증 계층을 추가했습니다.
- 실제 e-GIS 시도17 원본·속성2025·KOSTAT 출처 표기를 확인했습니다. 원기관 독립 원본 비교와 실제 지도 UI는 미검증입니다.
- 시군구→시도는 합산 가능성 확인, 전체 하위지역 포함, 분자/분모 원자료가 있을 때만 계산합니다. 비율 단순 평균·상위값 복제·누락 부분합은 차단합니다.
- 단계별 학생 화면·분야별 공식 자료/추천 후보 안내·Windows 오프라인 키트·교사 수동 검증 안내를 보완했습니다.

검증: 기존 엔진28·공간단위26·Worker4·로컬 브라우저18·키트23개, 기존 회귀3개 파일, 공개 산출물100개 검사 통과. 실제 통계 전체 파일과 지도 제작 검증을 대신하지 않습니다. 화순군60735/30.9/2605는 사용자 제공 단일지역 기준 재현이며 전남22개 실제 전수 성공이 아닙니다.

실제 KOSIS 전남22·전국 원본, 외국인/신혼부부/경지면적 원본, e-GIS 단계구분도 조작, 학교PC·학생 이해도는 미검증입니다. [공간 단위 보고서](spatial-units.md), [Windows 안내](windows-guide.md), [교사 체크리스트](classroom-checklist.md)를 확인하세요.
