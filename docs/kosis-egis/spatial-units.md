## 안전한 시군구 → 시도 집계

기본은 같은 단계로 결합합니다. 집계는 원본이 시군구이며 목표가 시도일 때만 별도 설정을 엽니다.

- **수량 합계**: 합산 가능한 수량임을 명시하고 확인해야 합니다. 비율·평균·밀도·지수와 % 표기는 합산하지 않습니다. 의미상 합산 가능 여부는 자료 정의를 확인한 교사가 판단해야 하며 헤더 검사만으로 통계 의미를 보증하지 않습니다.
- **고령인구비율**: Σ 고령인구수 ÷ Σ 전체인구수 ×100. 비율끼리 단순 평균하지 않습니다. 서로 다른 분자·분모 원자료 열과 확인이 필요합니다.
- **인구밀도**: Σ 인구 ÷ Σ 면적(km²). 면적 단위 확인이 필요하며 ha·㎡를 km²라고 자동 해석하지 않습니다.
- 교사가 교체한 기준표는 전수성이 확인되지 않았으므로 자동 시도 집계를 차단합니다. 같은 단계의 직접 결합만 확인 필요로 지원합니다.
- 시도마다 동일 기준의 모든 하위 시군구와 값이 있어야 계산합니다. 누락 지역·결측이 있으면 해당 시도는 빈칸이며 부분합을 완성된 값으로 출력하지 않습니다. 다른 시도가 완전해도 보고서는 누락을 알립니다. 중복·충돌은 중단합니다. 0은 결측이 아닙니다.
- 원본에 시도 합계행이 있으면 합계에 다시 더하지 않습니다. 수량은 같은 열로, 비율·밀도는 별도 지정한 원본 시도값 열로 비교합니다. 차이가 있으면 반올림·범위·지표정의를 확인하도록 중단하며 임의로 같다고 처리하지 않습니다.
- JSON·XLSX 집계 보고서에 계산식, 원자료 열, 범위, 기간, 누락 코드, 시도 원본값 비교를 기록합니다. 원본값대조표는 **집계 전 시군구 값**이며 최종 시도값의 직접 동등 비교표가 아닙니다.
- 다른 모집단·서로 다른 조사기준의 표를 섞지 않습니다. 자동 계산은 새로운 통계의 공식성이나 학술적 적합성을 보증하지 않습니다.

## 교사가 남겨야 할 최소 증거

1. 시도 통계 한 표 또는 전남22개 시군 통계 한 표를 같은 연도·한 항목으로 직접 다운로드해 원본 출처·표ID·항목·단위·기준일을 기록합니다. 세 자료 검증을 완료하려면 아래 세 원본이 각각 필요합니다.
2. 자동 추천 확인 → 변환 → CSV 다운로드 → `3-compare.cmd`로 원본과 실제 다운로드 CSV를 비교합니다. 시도 직접 결합은 `sido-actual-config-template.json`의 target_unit=sido, 시군구는 기존 설정을 사용합니다. 집계 결과는 직접 행 대조가 아닌 집계 보고서와 원본 시도값을 확인합니다.
3. e-GIS에서 같은 단계·연도의 경계 → 속성 code(시도2자리/시군구5자리) → CSV 결합 → 연결된 코드 수/숫자 있는 지역 수 확인 → 단계구분도·범례·결측 표시를 캡처합니다. 시도 전체17, 전남22가 실제 원본 범위와 같을 때만 그 수를 기대값으로 사용합니다.
