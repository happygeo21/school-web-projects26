# KOSIS → e-GIS 코드 대응 엔진 검토 · 2026-11-26

**진행 중 / 운영 배포 없음.** 학생이 임의 통계표를 전처리 없이 지도화할 수 있다는 최종 완료 기준은 아직 충족하지 않았다. 전국 후보를 검증 완료 대응표로 승격하지 않았으며, 현재 새 범용 경로에서 승인된 프로필은 0개다.

## SIMPLE · 학생 이용 범위

기존 `/kosis-egis/` 및 `/kosis-egis-tool/` 화면을 개선했다. 새 사이트·서버·유료 API는 만들지 않는다. SIMPLE은 지역 선택 → KOSIS 원본 입력 → 결과 확인 → CSV/e-GIS 네 단계를 유지한다. 일부 지역은 체크 목록에서 명시적으로 고른다. 검증 상태와 공식 출처는 하단 DETAIL에서 확인한다.

- PR #28의 2024 고령인구비율 전남 22개·전국 17개 원본 전용 경로와 원본값 대조 검사를 보존했다. 2024 통계/2025 경계의 차이에 대한 기존 경고도 유지한다.
- 다른 원본은 표 ID·기관·연도·항목 코드·전체 지역 계층을 읽는다. 공식 대응과 시점 호환 근거가 없는 표는 **CSV·XLSX·복사를 중단**하고 원인을 안내한다.
- 임의 CSV의 숫자코드가 지도와 같거나 이름이 같다는 이유로 내보내지 않는다. 수동 지역 수정·코드 열 선택 해제·기준표 교체·집계 확인 체크도 이 차단을 우회하지 못한다.
- 합성 연습자료는 기존 연습 기능이다. 통계자료 검증 성공 사례가 아니다.

## DETAIL · 원본과 전국 대조

공식 원본의 상세 출처·기준시점·다운로드 날짜·SHA-256·이용조건은 [source-manifest.json](source-manifest.json)에 기록한다. 원본을 수정해 후보를 만들지 않는다.

1. [공공데이터포털 행정동 정보](https://www.data.go.kr/data/15136373/fileData.do)의 과거 자료 `20250704` CSV를 실제 다운로드했다. 원본 30,532,809바이트를 무손실 gzip으로 보존했다. CP949, 실제 582,162행이며 페이지 표기 569,727행과 다르다. 파일 내부 최종 개정일은 2025-04-01이다. 배포 파일명 날짜를 모든 행의 유효일로 간주하지 않는다. 페이지의 최신 `20261001` 다운로드는 파일을 확보하지 못했다.
2. [행정표준코드관리시스템](https://www.code.go.kr/)에서 법정동 전체 ZIP을 다운로드했다. 존재/폐지 구분은 있으나 생성·폐지 날짜가 없어 2024–2025 호환성 증명이 되지 않는다. 원본 ZIP/TXT는 로컬에 보존하며 이용조건 확인 전 공개 저장소에 재배포하지 않는다.
3. e-GIS 배포 경계 2개를 다시 다운로드했다. 기존 시도 파일 SHA-256 `6be5d0089314a73783846dff2f7342682d588ebc1729de1e3a366d3c465c1265`, 시군구 `ed06f5c3489d1cdb3a744a7b1152d8c2308e2d9a609f5561f3d2dd3184654802`와 같았다. 시도 17개는 실제 code/name/base_year, 시군구 252개는 code/name/sido/sido_name/base_year를 전수 비교했다. 시도 파일에 없는 sido/sido_name은 자기 시도의 코드/이름이라는 기존 기준표 규칙이며, 원본 속성인 것처럼 기록하지 않는다.
4. [KOSIS 공식 코드 연계 안내](https://kosis.kr/civilComplaint/qnaDetail.do?boardIdx=22354)는 한국행정구역분류와 행정안전부 코드의 구분 및 기준시점별 연계DB 사용을 안내한다. 통계분류포털의 기존/현재 공식 호스트 모두 인증서 이름 불일치가 발생했다. 일반 HTTPS 요청에서도 같은 오류를 확인했고 인증서 검증을 해제하지 않았다. 사용자는 보유 연계DB 파일이 없으며 확보 가능한 자료로 계속 진행하도록 지시했다.

[official-audit.json](official-audit.json)과 [national-candidates.json](national-candidates.json)에 전국 269개 대상의 대조 기록을 남겼다. 법정코드+전체 이름 일치 267개, 통계코드의 시도+이름 단일 후보 234개다. **이 숫자는 승인된 코드 대응 수가 아니다.** 세종의 코드 단계 차이, 일반구의 상위 시 이름 생략 등은 별도 확인 대상이다. 후보는 런타임 공개 파일 목록에 넣지 않았다.

같은 숫자가 다른 지역을 뜻하는 충돌 13건을 기록했다. 예: `36`은 통계분류에서 전라남도, e-GIS에서 세종특별자치시이며, `11110`은 각각 노원구와 종로구다. 이름 후보는 검토 자료에만 남기고 학생 변환에서 우회 연결하지 않는다.

## 엔진과 기존 기능

첨부 seed ZIP SHA-256: `a96005cf9b4a6df87103d002e6ea22f5230058171d3839e21e1ddb814ed6e351`.

`region-crosswalk.js`는 seed의 일대일 순수 resolver를 확장했다. 테스트용 schema 1은 운영 승격을 거부한다. 운영 schema 2는 명시적 코드체계, 표/항목/기관/연도/공간단위, 전체 지역 계층, 공식 원본 출처, 경계 파일 해시, 관계 유형, 유효기간, 통계/경계 시점 호환 근거를 검사한다. 다대일·일대다, 미등록 코드, 중복, 누락, 이름/상위 시도 불일치가 있으면 출력은 빈 배열이다.

`kosis-workbook.js`는 기존 SheetJS와 core의 병합/숫자 처리를 재사용한다. 연간 한 시점, 코드 포함, 지역이 행인 KOSIS 데이터/메타정보 시트를 읽는다. 수식·통계값 병합·누락 항목 코드·다중 연도·미지원 분류 구조는 중단한다. 숫자 0과 결측은 구분하며 비율 평균/상위시 복제는 하지 않는다.

일반 업로드는 Worker의 strict 경로, 내장 합성 연습은 기존 공간 엔진, PR #28의 39개 고정 원본은 기존 전용 어댑터로 처리한다. `core.js`, `spatial.js`, 기존 기준표·GeoJSON·실전 산출물은 수정하지 않았다. 기존 엑셀 열 분석·원본 보존 다운로드·수치 검증은 유지한다. 기존 CSV 수동 교정의 허용 동작은 새 정확성 요구에 따라 의도적으로 차단했으며 브라우저 회귀 검사의 기대 결과도 변경했다.
