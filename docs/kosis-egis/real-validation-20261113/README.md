## 실제 e-GIS (로그인하지 않은 별도 브라우저 탭)

1. 데이터 불러오기 → 실습 데이터 → Area Data(면) → 행정경계. 실제 목록은 시도 16개(통합 이후)와 17개(통합 이전)를 구분한다. **대한민국 시도(~2026.06.30.) 17개** 선택.
2. 경계 이름을 클릭해 선택 → 레이어 → 테이블 결합. 실제 키 목록 code/name/name_eng/base_year 확인. 수정 변환기에서 내려받은 B_verified.csv 17행을 업로드.
3. 양쪽 키 code 선택. 미리보기 매칭 17·미매칭 0·100.0%. 실행 후 ‘조인된 피처 17/17’ 확인.
4. 주제도 → 단계구분도 → aging_pct → 동일간격 5등급. 기본 범례는 정수 반올림이므로 소수점 2자리·%로 변경. 범위 11.60~27.20%.
5. 프로젝트 저장: 실제 .egis 수신. 저장 파일의 결합 레이어와 단계구분 레이어 각각 17개 이름·code·aging_pct·원본 코드·year·unit 전수 일치. 재열기 복원은 미검증. e-GIS가 원본 코드 필드를 숫자형으로 추론했으나 해당 코드 값은 모두 보존됨.
6. PDF 실제 수신·렌더 검수 완료. 첫 출력은 제주 잘림, 두 번째는 출처 상자 가림을 발견해 축척 1:7,000,000 및 제목 내 출처로 수정. 최종 HappyGEO_2024_시도17_수업검증.pdf는 제주·범례·단위·제목·출처 표시 확인. 웹 배경지도 제외.
7. PNG 파일 수신은 여러 시도 후에도 확인되지 않아 **미검증**. 화면 캡처/위 PNG는 PDF 렌더 또는 UI 증거이며 e-GIS PNG 내보내기 성공 증거가 아니다.

실제 경계의 코드·지역 대응은 확인했지만 기존 2025 GeoJSON과 기하학적으로 동일하다는 검증은 하지 않았다. 결합 시 base_year도 CSV에서 복사되었으므로 저장 파일의 base_year=2025를 현재 경계 연도의 독립 증거로 삼지 않는다. 통계 2024와 경계 기준시점 차이는 교사가 확인해야 한다. 전남 22개는 이번 실제 사이트에서 별도 재현하지 않았다.

## 최소 수정과 자동 검증

- aging-xlsx.js: 정확히 검증된 표/항목/연도·2개 원본 형식만 처리. 메타정보, 병합/수식, 전체 계층, 코드, 지역 수, 공식값 스냅샷, 기존 지도 기준표 대조. 추측 변환 없음. 공식값 수정·다른 다운로드 형식은 재검증 전 거부.
- app.js: 해당 원본일 때만 어댑터 사용. 원본표 보존 다운로드 및 기존 감사 CSV 스키마 유지. 기존 합성자료/API 흐름으로 전환하면 전용 상태 해제.
- 기존 두 HTML에 어댑터 연결, 공개 파일 허용 목록 추가. Pages 배포는 실행하지 않음.
- egis-student-guide/index.html: 기존 내용 유지하며 2~6차시 14개 행동을 한 카드씩 표시. 성공 기준과 기기 제한 경로 추가. 학교 평가계획을 변경하지 않음.
- core 28 / spatial 27 / worker 4 / 실제 XLSX 회귀 33 통과.
- 기존 browser 18 / student-flow 9 통과. 실제 XLSX·오류 차단·차시 안내 브라우저 검사 15 통과.
- 실제 화면 검사는 데스크톱 Edge 390/820/1365px, 기존 학생 흐름은 320/390/834/1365px. 실기기나 Safari/WebKit 검사가 아님.
- 비배포 빌드/허용 목록 검사: 104개 파일 통과. 신규 XLSX/공식 조회 응답/검증 문서는 Pages 허용 목록에 넣지 않음.

실행: npm --prefix tests/kosis-egis test 및 CHROMIUM_PATH 지정 후 npm --prefix tests/kosis-egis run test:browser. 변경한 브랜치만 Draft PR로 검토하며 main 병합·배포 없음.
