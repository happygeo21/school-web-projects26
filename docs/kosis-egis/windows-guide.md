# Windows 교사용 실행·실제자료 검증 안내

대상 PR #8 / 기준 44a5fa7 이후 동일 브랜치의 수업 준비 수정본. 실제 데이터·실제 지도 UI 최종 검증 전입니다. 이 키트는 운영 배포가 필요 없습니다. 원격 브라우저 자동화와 네트워크 설정 변경을 하지 않습니다.

## 1. 다운로드와 실행

압축파일 손상 여부는 다운로드 폴더의 PowerShell에서 `Get-FileHash .\egis-windows-validation-kit.zip -Algorithm SHA256`로 계산해 함께 제공한 `.zip.sha256` 값과 대조할 수 있습니다. 압축을 푼 뒤 처음 실행 전에는 키트 폴더에서 `node check-integrity.cjs`를 실행해 포함 파일을 검사합니다. 해시 일치는 출처에 대한 보안 감사를 대신하지 않습니다.

1. 채팅에서 제공한 `egis-windows-validation-kit.zip`을 다운로드합니다. ZIP을 마우스 오른쪽으로 눌러 **모두 압축 풀기**를 선택합니다. OneDrive 공유 폴더 대신 자신의 로컬 작업 폴더를 권장합니다. ZIP 안에서 CMD를 직접 실행하지 마세요.
2. Node.js가 없다면 https://nodejs.org/ 의 공식 LTS(22 이상)를 학교 PC 관리 정책에 따라 설치합니다. 설치 승인이 필요한 학교 PC는 담당자에게 요청하세요. 키트는 프로그램을 자동 설치하거나 관리자 권한을 요청하지 않습니다. Python이나 npm install은 필요 없습니다.
3. 탐색기에서 `windows-kit` 폴더를 엽니다. 필요하면 메모장으로 CMD와 JS 내용을 먼저 확인합니다. `2-test.cmd`를 더블클릭하면 합성자료 점검을 실행합니다. 마지막 Exit code 0을 확인합니다. 결과는 evidence/local-tests/실행시각 폴더에 자동 저장되며 합성자료 전용 결과임을 표시합니다. 오류표본 내부의 FAIL은 기대한 차단이며 마지막 종합 판정을 확인하세요.
4. `1-start.cmd`를 더블클릭합니다. 열린 창을 유지하고 Edge/Chrome에서 **http://127.0.0.1:8000/kosis-egis/** 를 엽니다. 이 주소는 자기 PC 전용입니다. 외부 공개 서버·터널을 만들거나 방화벽·프록시·백신·실행 정책을 끄지 마세요. Windows가 실행을 막으면 학교 정책에 맞춰 담당자에게 확인합니다.
5. 변환기가 열린 뒤 ‘전남22 연습자료’를 넣어 봅니다. 끝나면 서버 창에서 Ctrl+C로 종료합니다. 8000 포트 사용 중 오류가 나면 자신의 이전 키트 창만 닫으세요. 알 수 없는 프로세스를 종료하지 않습니다.

서버는 `site/`만 읽으며 원본 파일이 있는 키트 루트는 웹으로 제공하지 않습니다. 서버는 외부 네트워크 요청을 만들지 않습니다. 화면의 KOSIS·e-GIS 링크를 누르면 사용자의 일반 브라우저에서 해당 사이트가 열립니다. 교사용 API 조회는 이번 수동 검증에서 사용하지 마세요.

학교 PC에서는 `Node.js 22+`만 추가로 필요합니다. CMD는 Windows용으로 작성했지만 자동 검증은 Linux/Node와 Windows CI에서 수행했으며 학교 보안 정책과 PC 구성은 별도이므로 **Windows CI의 CMD3개·로컬 Edge는 통과했고, 학교 Windows10/11 실기 확인은 미검증**입니다. SheetJS는 기존 PR과 동일한 0.18.5 버전이며 패키지에 라이선스를 포함합니다. 임의 파일·매크로 파일 대신 공식 사이트에서 받은 XLSX/XLS/CSV만 사용하세요. Excel 매크로 활성화는 필요 없습니다.

위 사업체 표ID·항목·산업전체·전규모는 공식 메타데이터에서 확인했습니다. 통계값·정확한 기준일·단위와 실제 다운로드는 아직 미검증입니다. 메타데이터 확인이 수치 검증 완료라는 뜻은 아닙니다. 사업체 통계의 조사대상·포함/제외 산업을 표 주석에서 확인하고 세 지도 해석에 기록하세요.

세 자료 공통 설정:

- 전국을 분석하면 전국 시군구, 전남이면 해당22개, 표본이면 해당 지역만 선택합니다. 전국·시도 합계와 수원시 같은 상위 시 합계는 실제 일반구와 구분합니다. 시도 합계17개뿐인 표를 시군구 자료로 쓰지 않습니다.
- 다른 연도로 수업을 설계한다면 가능하면 경계 기준과 같은 자료연도를 선택합니다. 사업체 자료가 더 오래된 연도까지만 있으면 실제 연도를 그대로 기록하고 경계 불일치를 확인 필요로 남깁니다. 세 자료의 연도가 다르면 같은 시점이라고 해석하지 않습니다.
- 표 제목·작성기관·표 ID·선택 항목·단위·통계연도/월·기준일·원문 URL·다운로드일을 각각 기록합니다. 갱신일은 통계 기준일이 아닙니다. 비율(%)과 인원수(명)를 혼동하지 마세요.
- 다운로드 → Excel(XLSX), 셀 병합 해제를 권장합니다. 원본 파일은 `original/`에 그대로 보관하고 Excel에서 덮어쓰지 않습니다. 아래 예시 파일명은 **사용자가 직접 받은 실제 파일의 이름**이며 키트에 실제 통계가 포함돼 있다는 뜻이 아닙니다.
- 차단·로그인 안내가 나오면 정상 브라우저 안내와 자신의 계정을 사용합니다. 키·쿠키를 키트에 넣거나 접근 차단을 우회하지 않습니다. 계속 실패하면 시각과 화면을 기록하고 해당 검증을 미검증으로 남깁니다.

## 3. 원본 엑셀 → 변환기 → 실제 다운로드 CSV 비교

### A. 변환기 입력

1. `1-start.cmd`로 연 로컬 변환기에 **직접 다운로드한 원본 XLSX/XLS**를 넣습니다.
2. 자료 시트(메타/설명 시트가 아님)를 선택합니다. 헤더가2줄이면 헤더 시작 행과 줄 수를 지정하고 미리보기에서 지역·숫자 열을 확인합니다.
3. 지역명·시도·코드·통계 열을 확인합니다. KOSIS 분류코드가 지도 code와 다른 체계면 원본 통계표를 먼저 선택하고 시도·지역명·원본연도를 확인합니다. 확인된 화순군 교차표 이외의 원본코드는 교사가 검토한 별도 교차표가 필요합니다. 코드 열을 선택해제해도 원본 코드를 무시하지 않습니다. code가5자리라는 이유만으로 같은 체계라 판단하지 않습니다.
4. 지표는 하나, 자료 기준연도와 분석 범위를 정확히 선택한 뒤 변환합니다. 중복·충돌·미매칭을 해결하기 전에는 성공으로 표시하지 않습니다. 일반구 값이 없으면 상위 시 합계를 복제하지 않습니다.
5. 지도용 CSV와 검증 JSON을 다운로드해 `downloads/`에 보관합니다. 이름 예: population-converted.csv, aging-converted.csv, business-converted.csv. CSV를 Excel에서 열었다가 다시 저장하지 말고 그대로 비교합니다.

### B. 직접 원본과 비교

이 단계는 변환기를 다시 실행해 결과를 만드는 과정이 아닙니다. **원본 XLSX/XLS와 A에서 실제 받은 CSV 두 파일**을 비교합니다.

1. `population-config.json`, `aging-config.json`, `business-config.json`에는 확인된 표ID·항목·URL·2024년을 미리 넣었습니다. 실제 파일에 맞게 남은 REPLACE 항목을 채우세요. 다른 통계는 `excel-actual-config-template.json`을 복사해 설정합니다. Notepad로 다음을 입력하고 UTF-8로 저장합니다.
   - synthetic=false 유지. period는 실제4자리연도. 월별자료이면 period_value를 `202512`처럼 원본 시점 셀과 같은 값으로 지정합니다. 원본 시점 열이 없으면 columns.year를 빈 문자열로 둡니다.
   - sheet는 엑셀의 정확한 시트 이름. header_start는 첫 헤더의 실제 행번호(1부터), header_depth는 헤더 줄수.
   - columns는 원본 열 이름. 여러줄 헤더는 ‘2025 / 총인구수’처럼 `/`로 연결되므로 변환기 미리보기와 비교하세요. 코드/시도/시점 열이 없으면 해당 값은 `""`로 둡니다.
   - output_value는 **다운로드 CSV의 실제 통계 열 이름**. 임의로 value라고 추정하지 않습니다.
   - source의 REPLACE를 실제 표 제목·ID·항목·단위·기준일·원문URL·다운로드일로 모두 교체합니다.
2. code_system은 지도와 같은 코드임을 확인한 경우에만 GIS로 둡니다. 다른 KOSIS 코드이면 SOURCE로 둡니다. SOURCE 모드도 미확인 코드를 이름만으로 자동 연결하지 않습니다. 알려진 화순군 교차표 또는 교사가 근거와 함께 검토한 행 교차표가 필요합니다. 별도 시도 열 또는 ‘전라남도 화순군’처럼 시도가 포함된 이름이 있어야 합니다. ‘중구’만 보고 임의 시도를 추정하지 않습니다.
3. 전국/시도 합계·설명행을 제외해야 하면 **원본 엑셀 행번호**와 이유를 exclude_rows에 적습니다. 예: `"exclude_rows":{"4":"전국 합계 — 분석대상 시군구 아님"}`. 제외 개수와 내용을 보고서에서 확인하세요. 미매칭 지역을 단순히 제외해서 통과시키지 않습니다.
4. 원본이 계층표여서 시도/상위시가 별도 행에만 나오면 교사가 실제 행과 경계를 확인해 명시적 행 교차표를 작성합니다. 예: `"row_regions":{"12":{"code":"11140","original_name":"중구","reason":"원본 10행 서울특별시 문맥과 해당 경계 속성 직접 확인"}}}`. 원본명 일치·대상 코드·이유를 검사하고 보고서에 남깁니다. 검토 없이 복사하지 마세요.
5. 폴더의 빈 곳에서 Shift+마우스 오른쪽 → 터미널/PowerShell 열기를 선택합니다. 실제 파일명에 맞춰 실행합니다. 아래 PowerShell 명령은 실제 데이터가 들어온 뒤 실행하는 예시입니다.

```powershell
.\3-compare.cmd ".\original\population.xlsx" ".\downloads\population-converted.csv" ".\population-config.json" ".\evidence\population"
.\3-compare.cmd ".\original\aging.xlsx" ".\downloads\aging-converted.csv" ".\aging-config.json" ".\evidence\aging"
.\3-compare.cmd ".\original\business.xlsx" ".\downloads\business-converted.csv" ".\business-config.json" ".\evidence\business"
```

`3-compare.cmd`는PowerShell 실행정책을 바꾸지 않습니다. 공백·한글이 포함된 경로도 따옴표로 감쌉니다. 마지막 인자는 필수는 아니지만 자료별로 다른 폴더를 권장합니다. 덮어쓰기 방지를 위해 재검증은 새 폴더명을 사용하세요.

### C. 판정과 증거

- `original-vs-downloaded.json`: 원본·CSV SHA256, 출처, 비교 행수, 제외 목록·사유, 중복·미매칭·기간·메타데이터·값 오류, 원본 코드→GIS code, 실제 e-GIS UI 미검증 표시.
- `audit.csv`: 원본 실제 행번호와 원래 수치, 기대값, 결과값, 일치 여부를 모든 비교지역에 대해 출력합니다. 교차표는 JSON의 checks에 기록됩니다.
- 비교 PASS는 **선택한 원본행과 실제 다운로드 결과의 일치**입니다. 전국 전수 여부·원본의 지역 누락·연도 적합성·지도 UI 성공은 별도 확인해야 합니다.
- 비교행0이면 실패. 숫자를 바꾼 결과, 중복코드, 누락 지역, 잘못된 지역메타데이터는 실패합니다. 결측은0이 아니며 0·음수·소수·퍼센트포인트를 구분합니다.
- 실제 통계 세 자료는 이 작업에서 아직 확보하지 못했습니다. 합성자료 config를 실제 파일에 사용해 통과로 표시하지 마세요.


## 4. e-GIS 시군구→code 결합→단계구분도

1. 일반 브라우저에서 https://www.e-gis.kr/ 을 열고 실습 데이터 → Area Data(면) → 행정경계 → 대한민국 시군구(252개,2025)를 선택합니다. 메뉴가 바뀌었으면 키트의 실제 `egis-sigungu.geojson`을 파일 불러오기로 넣습니다.
2. 레이어→속성 테이블을 열어 code가 문자열5자리인지, 피처252개인지 확인합니다. 이 키트의 실제 파일은 reference와5개 필드가 전수일치했지만 **교사가 연 현재 레이어**도 같은 파일인지 확인하세요. 시도 레이어나 다른 연도 레이어를 대신 쓰지 않습니다.
3. 레이어→테이블 결합에서 대상 레이어를 시군구로, **지도 쪽 키 code ↔ CSV 쪽 키 code**로 지정합니다. 필드명이 다르게 인식되면 실제 값과 의미를 확인해야 하며 `_1`이라고 단정하지 않습니다. 통계 숫자 열을 선택하고 실행합니다.
4. **코드가 연결된 피처 수와 숫자가 실제 있는 피처 수를 따로 기록**합니다. 전국252행을 빈값까지 채운 CSV라면 코드 결합252여도 값이있는 지역은22뿐일 수 있습니다. JSON의 code_key_matches·nonempty_value_matches와 UI를 비교하세요. 빈값이0으로 바뀌면 실패입니다.
5. 합성 전남22 연습은 키22·값22, 합성 전국252 연습은 키252·값252가 기대값입니다. 실제 통계는 독립 비교보고서와 선택한 원본 범위에 따라 기대값을 정합니다. 무조건252가 정답은 아닙니다.
6. 종로구11110, 화순군46790, 서울/부산/대구 중구 각각의 코드·숫자를 원본과 대조합니다. 자료에 없는 지역이면 ‘미포함’으로 기록합니다. 상위시 합계가 일반구에 복제되지 않았는지 확인합니다.
7. 주제도→단계구분도에서 대상 레이어와 **실제 통계 숫자열**을 선택합니다. code·base_year를 지표로 선택하지 마세요. 처음은 등간격 또는 분위수5구간 등 하나를 선택해 적용하고, 화면·범례·구간 경계값을 기록합니다. 결측색과 최솟값·최댓값을 확인하고 지도 제목·단위·자료시점·출처·경계연도를 적습니다.
8. `01-layer.png`(필드·피처수), `02-join.png`(설정·코드결합수), `03-values.png`(결합후 값), `04-choropleth.png`(지도·범례)로 캡처합니다. UI 명칭·구간·값이 실제 확인된 경우만 체크합니다.
