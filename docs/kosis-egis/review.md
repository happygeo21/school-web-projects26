## 정확성·상태 정책

- 기준표 형식: code 5자리, sido 2자리와 접두 일치, name·sido_name 필수, base_year 4자리, 코드·시도별 이름 중복 금지.
- 시도별 수(기존 표): 서울25·부산16·대구9·인천10·광주5·대전5·울산5·세종1·경기44·충북14·충남16·전남22·경북23·경남22·제주2·강원18·전북15 = 252. 이것은 내부 일관성 검사이며 원본 레이어와 비교한 증거가 아닙니다.
- 시도 문맥 없는 중구/동서남북구·고성군을 임의 선택하지 않습니다. 고유 지역명을 만났다는 이유만으로 다음 행의 시도를 추정하지 않습니다. 명시된 시도 행은 KOSIS 계층 표의 문맥으로 사용합니다.
- 수원시 등 상위 시 합계를 하위 구에 복제하지 않습니다. 코드·이름·시도 충돌, 중복 지역(연도·항목·성별 등)은 보고하고 중단합니다. 중복 첫 값·합계·평균을 임의 채택하지 않습니다.
- 전국/시도/일부 표본을 구분합니다. `결합 가능`은 선택 범위에 대한 로컬 검사 결과이며 실제 지도 결합 인증이 아닙니다. 표본은 항상 확인 필요입니다.
- 수동 지역 지정·제외는 보고서에 기록하고 재검증합니다. 설정·파일·시트를 바꾸면 이전 결과 저장을 비활성화합니다.

## e-GIS 수동 검증서

1. https://www.e-gis.kr/ 에서 사용하는 경계 레이어와 원본 속성 파일을 확보합니다. 레이어명·출처·경계기준일·실제 키 필드명·형식·고유 지역수를 기록합니다.
2. 실제 키·지역명·시도와 내장 reference 252개를 코드별 전수 대조합니다. 2025년 명칭/개편이 다르면 교사용 기준표를 해당 원본으로 교체합니다.
3. **합성 전남22** CSV로 연습: 실제 코드가 reference와 일치하는 경우 ‘레이어 → 테이블 결합’에서 지도 키(실제 필드명) ↔ 속성 `code`를 선택합니다. 예상 고유 결합=22, 전국 레이어일 경우 나머지는 결측이며 0이 아닙니다. 전남만 지도화하는 경우 레이어도 같은 범위를 선택합니다.
4. `synthetic-normal.csv`의 화순군은 code 46790, 연습값 1234.5입니다. 원본과 결합 후 값이 같은지 확인합니다. 서울·부산·대구 중구는 다른 코드인지 확인합니다.
5. `synthetic-missing-gu.csv`: 수원시 합계100을 일반구에 복제하면 실패입니다. 장안구20만 결합되고 다른 구는 빈값이어야 합니다.
6. 속성 테이블에서 결합수·빈값·중복을 확인한 화면과 ‘주제도 → 단계구분도’의 숫자열·범례·단위를 캡처합니다. UI 명칭은 실제 서비스에서 확인합니다. 이 문서에는 실제 화면을 꾸며 넣지 않습니다.
7. 실제 KOSIS 세 자료를 같은 절차로 반복하고 원본 표와 전수 값 비교 후에만 ‘통과’로 바꿉니다.

- `scripts/public-files.json`: 새 앱 의존성만 명시적으로 공개. 테스트·Worker 서버·문서는 공개 산출물에 넣지 않음.
