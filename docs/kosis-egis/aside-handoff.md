## 진행 순서

1. 배포 SHA·시각·실행 URL·브라우저를 기록합니다. 첫 화면에 전국 시도/전국 시군구/특정 시도/자동 추천이 있고 XLSX.version=0.20.3인지 확인합니다. 다른 화면이면 예전 배포입니다.
2. 비교 지역 선택 → 공식 KOSIS에서 같은 시점·한 항목의 실제 XLSX 다운로드 → 원본 그대로 보관 → 변환기에 입력 → 시트/헤더/지역·시도·코드·연도/단위 확인 체크 → 변환·CSV/검증 JSON 다운로드.
3. 시도 지도 한 개, 시군구 지도 한 개를 각각 만듭니다. 가능하면 시도17개 인구와 전남22개 시군 통계를 사용하되 실제 제공 행 수를 확인하고17·22·252를 강제로 채우지 않습니다. 합성 연습값은 조작 연습에만 사용하고 실전 통계 검증과 분리합니다.
4. e-GIS에서 같은 시점·공간 단위의 실제 경계를 불러옵니다. 지도 속성과 CSV의 code 형식·고유 개수·이름을 대조하고 지도 code ↔ CSV code를 연결합니다. 코드 연결 수와 실제 숫자가 있는 지역 수를 따로 기록합니다.
5. 원본 XLSX→실제 다운로드 CSV의 지역코드·통계값을 전수 비교합니다. [Windows 안내](windows-guide.md)의 `3-compare.cmd`를 사용합니다. 시도는 target_unit=sido, 시군구는 sgg. 원본 코드체계가 다르면 검토한 교차표가 필요하며 이름만으로 치환하지 않습니다.
6. e-GIS 속성값을 원본/CSV와 대조한 뒤 숫자 열로 단계구분도를 만듭니다. 범례 구간·단위·출처·자료연도·경계연도·빈값 표시를 확인하고 경계 속성/결합 설정/결합 후 값/지도와 범례를 캡처합니다.

## 경계·코드 원칙

- 내장 시도17개: 문자열2자리 code, base_year2025. e-GIS 카탈로그 KOSTAT 표기와 실제 배포파일 확인. 통계청 직접 배포본과 독립 형상 비교는 미검증. 카탈로그 버전명 ~2026.06.30.과 속성연도를 구별합니다.
- 내장 시군구252개: 문자열5자리 code, base_year2025. 전남 하위는22개. 기존 실제 경계5개 속성과 기준표 일치 확인. 상위 시 합계와 일반구가 섞이면 중복 없이 원본 범위부터 확인합니다.
- 시도 통계를 시군구 전체에 복제하지 않습니다. 단순 비율 평균·분모 없는 비율 집계·누락 부분합은 금지합니다. 교체한 부분 기준표로 시도 전체 합계를 만들지 않습니다.
- KOSIS 분류코드는 GIS 행정코드와 다를 수 있습니다. 사용자 외부조회 화순군2024 기준은 아래 세 점뿐입니다. 공식 원본 독립 전수검증이 아닙니다.

| 표/항목 | 원본코드 → GIS | 사용자 제공 값 |
|---|---|---|
| org101 DT_1B040A3 / T20 | 46790 → 46790 | 60735명 |
| org101 DT_1YL20631 / T10 | 1236370 → 46790 | 30.9% |
| org118 DT_118N_SAUPM78 / 16118ED_1 | 2017zone_3637 → 46790 | 2605개(산업전체·전규모) |

12760을 이름 검색만으로 화순군에 연결하지 마세요. 원본 시도·지역명·표·항목·시점까지 검증합니다. 화순군 한 지역을 확인해도 전남22개 전수 성공이 아닙니다. 상세 조회 설정은 [공간 단위 안내](spatial-units.md)에 있습니다.

## Codex에 전달할 결과 형식

```text
검증일 KST / 담당 / 브라우저:
배포 SHA / URL:
자료: 공식 URL, 기관, 표ID/항목, 단위, 기준일, 다운로드일, 원본 SHA256
원본 행수 / 제외 행과 사유 / 공간 단위 / 대상 범위:
원본코드→GIS 교차표 근거:
변환 성공 / 중복 / 누락 / 결측 / 0 / 값 불일치 수:
CSV/XLSX 각각의 전수 비교 판정과 보고서 파일:
e-GIS 경계 출처·연도 / 실제 키 / 코드결합수 / 값보유 지역수:
단계구분도 분류법·구간 / 범례·빈값·표본 원본값 대조:
통과 / 실패 / 미검증과 각 근거파일:
오류: 재현 순서, 화면 문구, 민감정보를 제거한 최소 표본:
```

학생 기록·평가·계정/쿠키·API키·토큰은 첨부하지 않습니다. 접근이 차단되면 우회하지 말고 URL·시각·응답/화면을 기록합니다. 실전 검증 결과만 Codex에 전달하며 main 직접 수정이나 운영 데이터 쓰기는 수행하지 않습니다.
