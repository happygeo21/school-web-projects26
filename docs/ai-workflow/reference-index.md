## 자료 사용 한계

제공 텍스트에 포함된 주장·요금·별점·모델·지원률·설치 명령은 현행 검증 결과가 아니다. 도입 시 공식 자료를 확인한다. 원문의 인터랙티브 데모, 코드 복사 결과, 스킬 ZIP, 이미지 파일은 이 텍스트만으로 전달되지 않았으므로 설치·동작을 보장하지 않는다. 여기의 기준은 향후 작업에서 필요에 맞게 적용하며 현재 모든 앱을 소급 변경하지 않는다.
