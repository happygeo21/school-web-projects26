1. 목적·대상·기준 원본·변경 허용 범위·산출물·완료 조건부터 확인한다. 지난 대화의 완료 보고와 현재 실행 상태를 구분한다.
2. 프로젝트 현황은 목적 / 기준 원본 / 운영 주소 / 마지막 확인일 / 미해결 문제 / 다음 행동으로 추적한다. 중복 페이지·DB·자동화를 만들기 전에 기존 자산을 확인한다.
3. 학생 관점의 사용성, 교과 목표→활동→평가 연결, 문항의 정답/복수정답, 데이터의 누락/중복/원문 추적을 해당 업무에서 검토한다. AI 모의검토를 실제 학생 검증으로 부르지 않는다.
4. 결과 보고: 결과물 링크 / 변경 사항 / 직접 검증한 항목 / 미검증 항목 / 위험 / 교사 승인 필요 여부. 테스트하지 않은 것은 완료라고 말하지 않는다.
5. 학생 실명·학번·성적·상담·출결·비밀키를 공개 HTML·GitHub·결재함에 기록하지 않는다. 평가 확정·대외 발송·운영 배포·원본 삭제·권한/보안 변경은 별도 승인 원칙을 따른다.

## HTML 신규 제작·실질 개편
- **편집 가능한 결과물**을 기본값으로 하되 일반 보기와 접이식 교사용 편집 패널을 구분한다. 단순 오탈자 수정은 불필요한 전면 개편을 강제하지 않는다.
- **보고서/학습지:** 문단 흐름, 글·표·이미지·섹션 편집, A4 여백/페이지 나눔.
- **발표/포스터:** 요소 이동·크기·회전·정렬·앞뒤 순서·그룹·잠금, 슬라이드 추가·복제·삭제·재정렬, 미세 이동.
- **학생 웹앱:** 교사용 콘텐츠 편집과 학생용 제출·로그인·계산·보안 로직을 분리한다.
- **안내 페이지:** 가벼운 글·이미지·링크·섹션 편집.
- **공통:** 서식·찾기/바꾸기; 표 전체 삭제, 행열 추가/삭제, 셀 병합/분할, 폭/테두리; 이미지 삽입/교체/삭제; 블록 이동/복제/삭제; 실행 취소/다시 실행; 드래그 없는 이동 대안.
- **보존:** 재편집 가능한 파일, 편집 상태 JSON 백업/복원, 저장 표시, 저장 후 재열기 확인. 임시 브라우저 저장과 파일 저장을 구분한다.
- **출력:** 인쇄/PDF 저장과 직접 PDF 생성 기능을 구분하고 편집 UI 숨김, 한글·표·이미지 잘림, 용지/여백을 검사한다.
- **검증:** 한글 입력→표 삭제/되돌리기→행열/셀 조작→이미지 교체/블록 이동→저장·재열기→JSON 복원→대표 학생 흐름→실제 PDF. 미실행은 '미검증', 비해당은 '해당 없음'. 브라우저 반응형 검사와 실제 iPad 테스트를 구분한다.
- 무료·로컬·Windows/iPad 호환을 우선한다. 기존 검증된 편집기 재사용; Tiptap, GrapesJS 등은 목적과 라이선스에 맞게 선택하며 무조건 의존하지 않는다.

### 1. 모호한 자연어도 기존 자산 우선
- “HTML 만들어줘”, “지리 웹앱 수정해줘”, “시험 그래프”, “학생 제출”, “AI 사무실에서 처리해줘”처럼 짧은 요청을 받더라도 **작업 유형 → 현재 원본/관련 PR → 산출물 → 최소 변경 → 검수** 순으로 처리한다.
- 요청에 이미 포함된 목표·조건을 반복 질문하지 않는다. 도구 접근이 가능하면 실제 main/열린 PR/기존 앱을 조회하고, 확인 불가능한 완료·배포·계정 로그인 상태는 단정하지 않는다.
- **지침/참조 자료를 저장하는 행위는 실행 트리거가 아니다.** Notion AI 및 연결된 에이전트가 Skill을 활성화·읽을 수 있을 때에만 작업에 반영되며, 별도 승인 없는 병합·배포·자동화 생성은 금지한다.

### 2. 자료의 성격에 맞는 최소 기술 사용
| 자료 유형 | 우선 기술 | 주의 |
| --- | --- | --- |
| 정적·일회성 공개 자료 | 단일 HTML, 기존 GitHub Pages/Netlify | 공개 HTML/JS에 비밀키·개인정보 금지 |
| 자주 바뀌는 **공개** 퀴즈·답사 자료 | 별도 JSON/CSV 또는 공개 시트 + HTML | 공개 시트의 모든 행은 누구나 열람 가능 |
| 교사용 Google Sheets 반복 업무 | Sheets 함수·메뉴·Apps Script | 기존 시트를 원본으로 보존, 별도 테스트 사본 사용 |

| 기존 Firebase·Cloudflare Worker 앱 | 현재 검증된 구조 유지 | 목적 없이 Apps Script나 새 플랫폼으로 이전 금지 |

- Apps Script 웹앱은 필요한 값만 반환하고, 사용자의 로그인·승인 범위·데이터 접근을 서버 측에서 검증한다. `실행: 나`는 소유자 권한으로 처리될 수 있으므로 특히 주의한다. 운영 코드를 수정하면 **새 버전으로 배포 갱신하고 해당 URL에서 실제 검증**한다. 별도 배포 승인 없이 실행하지 않는다.
- **시트/CSV·HTML을 결합할 때** 콘텐츠(문항·국가·수도·좌표·설명)와 UI·채점 로직을 분리해 동일한 자료로 게임·퀴즈·지도·그래프를 재사용한다. 업데이트·결측·형식 오류를 검사한다.

### 4. HTML 편집·웹 참조 이미지 추가 원칙
- 검증된 기존 편집 엔진과 템플릿 재사용: 보고서·학습지(A4/문단/표), 발표·포스터(객체 이동·크기·복제·슬라이드), 학생 웹앱(학습 UI·교사 콘텐츠 편집 분리) 중 목적에 맞게 선택한다.
- 외부 웹페이지 `Ctrl+S` 저장본은 **디자인 참고본일 뿐 완전한 소스 보존 아님**. 코드·글꼴·이미지·라이선스와 출처를 확인하고 무단 복제하지 않는다.
- 외부 이미지 URL은 언제든 만료되거나 접근이 차단될 수 있다. 지속 사용할 자산은 이용 허락 범위 내에서 별도 보관하고 출처·권리·대체 이미지·미표시 처리 규칙을 둔다.
- 저장된 HTML 다시 열기, JSON 백업·복구, 표 전체 삭제·되돌리기, 실제 브라우저의 인쇄/PDF 및 한글 잘림을 확인한다. 가상 모바일 크기 검사와 실기기 검사를 구분한다.

### 5. PC·모바일 AI 개발과 운영 승인
- Windows PowerShell/CMD는 로컬 명령 실행 도구이다. Codex CLI·Antigravity 실행 가능 사실만으로 **서로 연결되거나 Happy GEO 웹의 자연어 명령이 자동 실행되는 것은 아니다.**
- 기본 역할: ChatGPT(기획·자료 준비) → Codex(코드 수정·테스트·브랜치/PR) → Antigravity(보조 개발·브라우저 검수) → GitHub(버전) → 교사 검수·별도 배포 승인. 이미 구독 중인 GPT·Gemini를 우선 활용하며 신규 유료 API/서버를 무조건 추가하지 않는다.
- 모바일 Codex 원격 제어는 지원 계정·데스크톱 앱·PC 가동·실제 연결·승인 후에만 사용한다. 클라우드 작업과 로컬 PC 작업은 구분한다.
- 기존 Notion 업무함·결재함/Telegram Worker/아이폰 음성 단축어의 역할을 보존하고 중복 알림·자동화·데이터베이스 생성을 피한다.
