# Happy GEO — 공통 AI 제작·검수 지침 v1.0

확정: 2026-11-06 (Asia/Seoul) · 기준 원본: [Notion 교사용 AI 공통 지침](https://app.notion.com/p/84e05f165f29470a9cf15123ac1ff02b)

## 모든 작업
1. 목적·대상·기준 원본·변경 허용 범위·산출물·완료 조건부터 확인한다. 지난 대화의 완료 보고와 현재 실행 상태를 구분한다.
2. 프로젝트 현황은 목적 / 기준 원본 / 운영 주소 / 마지막 확인일 / 미해결 문제 / 다음 행동으로 추적한다. 중복 페이지·DB·자동화를 만들기 전에 기존 자산을 확인한다.
3. 학생 관점의 사용성, 교과 목표→활동→평가 연결, 문항의 정답/복수정답, 데이터의 누락/중복/원문 추적을 해당 업무에서 검토한다. AI 모의검토를 실제 학생 검증으로 부르지 않는다.
4. 결과 보고: 결과물 링크 / 변경 사항 / 직접 검증한 항목 / 미검증 항목 / 위험 / 교사 승인 필요 여부. 테스트하지 않은 것은 완료라고 말하지 않는다.
5. 학생 실명·학번·성적·상담·출결·비밀키를 공개 HTML·GitHub·결재함에 기록하지 않는다. 평가 확정·대외 발송·운영 배포·원본 삭제·권한/보안 변경은 별도 승인 원칙을 따른다.

## HTML 신규 제작·실질 개편
- **편집 가능한 결과물**을 기본값으로 하되 일반 보기와 접이식 교사용 편집 패널을 구분한다. 단순 오탈자 수정은 불필요한 전면 개편을 강제하지 않는다.
- **보고서/학습지:** 문단 흐름, 글·표·이미지·섹션 편집, A4 여백/페이지 나눔.
- **발표/포스터:** 요소 이동·크기·회전·정렬·앞뒤 순서·그룹·잠금, 슬라이드 추가·복제·삭제·재정렬, 미세 이동.
- **학생 웹앱:** 교사용 콘텐츠 편집과 학생용 제출·로그인·계산·보안 로직을 분리한다.
- **안내 페이지:** 가벼운 글·이미지·링크·섹션 편집.
- **공통:** 서식·찾기/바꾸기; 표 전체 삭제, 행열 추가/삭제, 셀 병합/분할, 폭/테두리; 이미지 삽입/교체/삭제; 블록 이동/복제/삭제; 실행 취소/다시 실행; 드래그 없는 이동 대안.
- **보존:** 재편집 가능한 파일, 편집 상태 JSON 백업/복원, 저장 표시, 저장 후 재열기 확인. 임시 브라우저 저장과 파일 저장을 구분한다.
- **출력:** 인쇄/PDF 저장과 직접 PDF 생성 기능을 구분하고 편집 UI 숨김, 한글·표·이미지 잘림, 용지/여백을 검사한다.
- **검증:** 한글 입력→표 삭제/되돌리기→행열/셀 조작→이미지 교체/블록 이동→저장·재열기→JSON 복원→대표 학생 흐름→실제 PDF. 미실행은 '미검증', 비해당은 '해당 없음'. 브라우저 반응형 검사와 실제 iPad 테스트를 구분한다.
- 무료·로컬·Windows/iPad 호환을 우선한다. 기존 검증된 편집기 재사용; Tiptap, GrapesJS 등은 목적과 라이선스에 맞게 선택하며 무조건 의존하지 않는다.

## 운영 안전
- 작업은 별도 브랜치와 PR에서 검토한다. main 직접 변경·PR 자동 병합·운영 배포 금지(별도 승인 시 예외).
- 기존 Firebase, Telegram Worker, 웹훅, D1, Notion 원본·권한·학생 데이터 보존.
- 지침 파일을 GitHub에 둔다고 ChatGPT 계정 맞춤 지침, 개인 스킬, 외부 자동화가 자동 갱신되는 것은 아니다.
