# Happy GEO 기후 그래프 편집형 HTML — 시범 실행 01

> **실험용, 운영 미배포** · 고1 지리적 사고력 활동 · 가상 수치 전용 · 교사 승인 전 실수업 적용 보류

## 목적과 기준 원본

- 자연어 요청 “고1 기후 그래프 편집형 HTML 제작”을 `AGENTS.md`, [공통 제작·검수 기준](../../docs/HAPPY_GEO_COMMON_GUIDELINES.md), [Notion Happy GEO Skill](https://app.notion.com/p/410abbdcebdc81fab15cf60560cd4462)을 적용해 실제 산출물로 만든 **일회성 기능 검증**.
- 기존 [Notion A4 Print Studio](../../notion-print/index.html)의 A4·편집/출력 설계 원칙을 참고하되 해당 운영 파일은 수정하지 않음.
- 기존 [기후 그래프 풀이 5단계 학습자료](https://app.notion.com/p/3dbabbdcebdc819d9c12ce50f35cf6b0)의 관찰 순서(그래프→계절→기후→지도→선지)를 참고해 학생 질문 설계.
- 외부 CDN/API·DB 없이 **단일 HTML**. 가상 관측지 A·B의 12개월 데이터만 내장. 국가/실제 도시/실제 관측·KOSIS 수치가 아님.

## 사용법

1. `index.html`을 내려받아 브라우저로 열거나, 승인된 안전한 미리보기에서 실행한다.
2. 상단 **✎ 편집하기** → 교사 패널의 '기후 데이터'에서 월별 기온·강수량과 관측지 이름을 수정한다.
3. '문구·활동'에서 제목·학습 안내·질문을 수정하고, 질문 복제·재정렬·삭제로 활동을 바꾼다.
4. **JSON 백업** / **JSON 복원** 또는 **CSV 입출력**으로 데이터를 재사용한다.
5. **HTML 저장**으로 수정 상태가 포함된 자체완결 파일을 받는다. 그 파일을 **다시 열면 현재 편집 내용**이 나타난다.
6. **인쇄 / PDF** → 브라우저의 'PDF로 저장'으로 A4 한 장을 만든다. 교사용 편집 UI는 인쇄에서 숨긴다.

## 완료·미완료 경계

- **완료:** 시범 HTML 파일과 로컬 브라우저·PDF 기능 시험; 코드의 별도 브랜치/PR 준비; Notion 기록 예정.
- **미완료:** 실제 학생·교사 실사용, Windows/태블릿 실기기 파일 재열기, 접근성 전수 검사, 운영 배포, AI Office 웹 입력창의 무인 실행 엔진, 공식 실측 데이터 연동.
- 이 도구는 **고정된 12개월 기후 자료 편집기**다. 일반 문서의 셀 병합·분할, 자유 이미지 배치 등 범용 WYSIWYG 전체 기능은 이 소규모 시범의 대상이 아니며, [공통 제작 지침](../../docs/HAPPY_GEO_COMMON_GUIDELINES.md)의 해당 기능을 지원한다고 주장하지 않는다.

## 데이터·보안

- 학생 실명·학번·성적·상담·출결, API 키 및 인증 정보가 없다.
- 수치 자체가 가상이므로 실제 기후 분류·지역 추정에 근거로 사용 금지. 학생에게 이 사실이 항상 보이게 표시한다.
- 브라우저 다운로드는 사용자가 저장한 파일이며, 클라우드 자동 동기화/백업이 아니다. 사용자가 원하는 위치에 보관해야 한다.
- 운영 `main`, 기존 웹앱·Firebase·Worker·Notion DB의 런타임 변경을 동반하지 않는다.
