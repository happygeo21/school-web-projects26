비공개 신혼집 계산기·의사결정 ↗

브라우저 백업과 개인 정보 안내

체크리스트·예산·임시 메모는 브라우저 저장소(localStorage)에만 저장됩니다. 브라우저를 초기화하거나 다른 기기를 사용하면 나타나지 않을 수 있습니다. 노션 페이지의 공유 권한은 GitHub Pages와 독립적입니다.

이 사이트는 공개 정적 HTML이며 Notion API 토큰·비밀번호·주택 세부 금액 등 개인 정보를 코드에 포함하지 않습니다. 공동 실시간 동기화는 별도 인증된 서버를 구축해야 가능합니다.
