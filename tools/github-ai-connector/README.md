# GitHub → AI 도구 연결 도우미

- **반영일**: 2026-10-19 (Asia/Seoul) · 상세 시각은 GitHub Commit에 기록
- **실행**: [GitHub Pages](https://happygeo21.github.io/school-web-projects26/tools/github-ai-connector/)
- GitHub 공개 API를 이용해 README·SKILL.md 존재 여부를 살펴보고 설치 유형을 분류합니다.
- CORS/네트워크/API 제한 발생 시 원본 저장소와 API 링크로 수동 확인을 지원합니다.
- 읽기 전용 도구로 계정·로컬 파일·GitHub 저장소를 자동 수정하거나 AI에 스킬을 영구 설치하지 않습니다.
