# 한국 교사 업무 스킬

ChatGPT skills-only plugin. This is an independently authored instructional adaptation inspired by [NomaDamas/k-skill](https://github.com/NomaDamas/k-skill), **not a copy of the upstream project's executable helpers**.

The ZIP artifact is available in the ChatGPT conversation where this guide was generated. To package from this repository, zip the files in this folder with `plugin.json` at the archive root.

Includes four skills: `kosis-geography`, `hwp-workflow`, `korean-school-notice`, `academic-source-review`.

These skills do **not** provide live KOSIS API access, filesystem access, or kordoc automation. Those require separately connected tools. No API keys or private student data belong in this repository.
