# 공문 만들기 — kordoc 간편판 (원본 자료 안내)

이 폴더는 전북특별자치도교육청 **교직원 제작 도구**에 게시된
**「[공문 만들기] 메모 몇 줄을 무료 AI로 한글 공문서(HWPX)까지 — kordoc 공문서 기능 간편판」**의 출처와 이용방법을 기록합니다.

> **주의:** 이 문서는 원본 HTML 프로그램이 아닙니다. 실행하려면 아래 공식 게시물의 첨부 ZIP을 내려받아야 합니다.

## 원본 및 출처

- 공개 기관: 전북특별자치도교육청 (교직원 제작 도구)
- 게시자: 이리고등학교 한성준
- 게시일: 2026-10-09
- 원본 게시물: https://www.jbe.go.kr/board/view.jbe?boardId=BBS_0000683&menuCd=DOM_000000106011002002&dataSid=1187526
- 첨부파일: `공문만들기(kordoc 간편판).zip`
- 핵심 문서 생성 엔진: **kordoc** (© chrisryugj, MIT License)
- kordoc 원작 저장소: https://github.com/chrisryugj/kordoc

## 사용 방법

1. 위 교육청 공식 게시물에서 ZIP 파일을 다운로드해 압축 해제합니다.
2. HTML 파일을 크롬 또는 엣지로 엽니다.
3. 기관 정보와 문서 유형을 선택하고 `프롬프트 복사`를 누릅니다.
4. ChatGPT에 프롬프트와 개인정보를 제외한 업무 메모를 입력합니다.
5. 결과를 HTML에 붙여넣은 후 `HWPX 만들기`로 저장합니다.
6. 한글에서 쪽 나눔, 결재란, 표 및 내용의 정확성을 최종 점검합니다.

## 이용 시 주의

- **자료의 게시물에는 공공누리 제4유형(출처표시·상업적 이용 금지·변경 금지)이 표시되어 있습니다.** 원본 프로그램의 구체적인 재배포·개작 허용 범위는 별도로 확인해야 합니다.
- 상기 제약을 고려해 이 저장소에는 **원본 파일을 재배포하지 않고 공식 출처로 연결**합니다.
- 원본에 포함된 kordoc 및 제3자 오픈소스의 라이선스 표시는 그대로 존중해야 합니다.
- 학생 이름, 연락처, 주민등록번호 등 개인정보를 외부 AI 대화창에 입력하지 마세요.
- HTML 내 로컬 문서 변환 여부와 별개로 ChatGPT 입력 내용은 외부 서비스에서 처리될 수 있습니다.
- 이 간편판은 MCP 서버를 연결하는 프로그램이 아니라, AI 답변을 복사·붙여넣어 HWPX를 생성하는 독립 실행 HTML입니다.
