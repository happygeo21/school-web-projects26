원본 프로그램 사용하기

원본 HTML은 아직 이 GitHub Pages에 배포되지 않았습니다. 아래 공식 교육청 게시물에서 ZIP을 받아 압축을 푼 다음 HTML을 열면 바로 이용할 수 있습니다. 별도 MCP 설치는 필요 없습니다.

교육청 원본 다운로드 ↗ 사용법 · 출처

사용 절차

  1. 공식 게시물의 공문만들기(kordoc 간편판).zip을 다운로드해 압축 해제
  2. HTML 파일을 크롬 또는 엣지에서 실행
  3. 기관 정보 입력 → 문서 유형 선택 → 프롬프트 복사
  4. ChatGPT에 붙여넣고 초안 작성 → HTML에 결과 붙여넣기
  5. HWPX 만들기를 눌러 저장한 뒤 한글에서 최종 검토
