# 기억까지 몇 걸음?

기억의 좌표의 별도 지리 탐구 수업안. `index.html`을 브라우저로 열면 시작합니다.

- `index.html`: 학생 4단계 활동과 교사 안내·카드 모아보기
- `evaluation.md`: 기존 수업 진단, 50분·3차시 운영안, 평가·연구 보완안

기존 파일을 수정하거나 기존 Firebase에 연결하지 않습니다. 외부 라이브러리 없이 작동하며 외부 지도·출처 링크에는 인터넷이 필요합니다. 실제 지도 표시와 실시간 공동 제출 기능은 없습니다.

학생은 카드 JSON을 저장해 교사가 정한 경로로 제출합니다. 교사는 ‘교사 안내·모아보기’에서 여러 파일을 불러옵니다. 학생의 임시 기록은 해당 브라우저에 남고, 교사의 모아보기는 새로고침하면 사라집니다. 공유 기기에서는 저장 후 새 활동으로 기록을 지우세요.

공개 게시할 것은 도구이며 학생의 카드 JSON은 저장소에 커밋하지 않습니다.
