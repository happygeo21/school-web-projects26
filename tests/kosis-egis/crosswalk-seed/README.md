# Happy GEO — 공통 행정구역 코드 대응 엔진 / Codex 통합 시작점

## SIMPLE | 한 페이지 핵심
- 목적: 학생이 KOSIS에서 직접 받은 XLSX를 기존 변환기에 넣고, 지도용 CSV를 받아 e-GIS에 결합하도록 한다.
- 기존 웹: https://happygeo21.github.io/school-web-projects26/kosis-egis/ (새 사이트 불필요)
- 저장소: https://github.com/happygeo21/school-web-projects26
- PR #28: https://github.com/happygeo21/school-web-projects26/pull/28 (기존 검증 보존, 미병합 상태 확인)
- 이 ZIP은 공통 코드 대응 함수의 개발용 시드이며, 학생용 XLSX 변환기·운영 배포본이 아니다.
- 2024년 기존 자료 4종(전남22/시도17 고령인구비율, 서울25 1인가구비율, 시도17 합계출산율)의 총 81개 행을 회귀 fixture로 구성. 지역·값 대응 및 오류 차단 28개 테스트 통과. 원본 XLSX 처리와 실제 e-GIS UI는 이 ZIP에서 검증하지 않았다.
- 다음 행동: 공식 연계 DB 확보 → 전국 코드 레지스트리 작성 및 검증 → 기존 core.js·spatial.js에 통합 → 실제 KOSIS XLSX 및 e-GIS 지도 결합 검증. 학교 실기기 검증 후 별도 승인으로 배포.

## DETAIL | 개발자 안내

### 파일
- `region-crosswalk.js`: 정규화된 행을 대상으로 하는 순수 JS 지역 코드 검증/대응 함수. Node 또는 브라우저에서 불러올 수 있다. XLSX 파싱, 수치 결측/오류 검사, CSV 생성, 지도 결합은 기존 앱의 기능을 그대로 사용한다.
- `registry.fixture.json`: 실습·회귀 테스트 전용 코드 대응 레지스트리. 공식 전국 연계표가 아니다. 이전 검증 CSV에서 추출한 표별·연도별·공간단위별 제한 대응이다. 기본 실행에서 차단되고, `allowFixture:true`를 명시한 로컬 테스트에서만 허용한다. 운영 UI에서 이 옵션을 켜거나 데이터를 approved로 단순 변경하지 않는다.
- `cases.fixture.json`: 기존 산출물에서 추출한 정규화된 입력·기대값·기대 경계. 경계와 기대값이 같은 선행 CSV에서 추출되었으므로 독립적인 원본/경계 검증으로 간주하지 않는다.
- `region-crosswalk.test.cjs`, `test-results.txt`: 회귀 테스트와 이번 실행 결과. `node region-crosswalk.test.cjs` (Node 22, 별도 패키지 불필요).

### 운영용 레지스트리 구축
1. 공식 출처: [KOSIS 공식 Q&A](https://kosis.kr/civilComplaint/qnaDetail.do?boardIdx=22354), [통계분류포털](https://kssc.kostat.go.kr/) → 사회분류 → 일반분류 → 한국행정구역분류 → 기준시점별 연계DB조회, [행정표준코드](https://www.code.go.kr/), [공공데이터포털 행정동 정보](https://www.data.go.kr/data/15136373/fileData.do). 출처의 실제 파일, 다운로드 날짜, 기준시점, 해시, 이용조건, 데이터 사전과 행정구역 변경 이력을 기록할 것. 공공데이터의 행정동 정보는 연계표 자체와 같다고 가정하지 않는다.
2. 기존 `kosis-egis-tool/reference.json`, `sido-reference.json`, `sigungu-2025.geojson`, `sido-2025.geojson`, `boundary-provenance.json`의 실제 속성 대조. 2025년 경계는 17개 시도·252개 시군구 레이어 기준이며 현행 행정구역 또는 KOSIS 표의 행 수와 같다고 가정하지 않는다. 선택한 실제 지도 레이어의 속성/연도/범위와 코드도 확인한다.
3. 공식 표준 코드체계 레지스트리와 통계표별 분류코드/계층 어댑터를 분리한다. 테이블·항목·지역 차원·시점·상위 시도·공간 단위를 식별하고 공식 근거가 있는 1:1 연결만 허용한다. 이름/코드/상위 지역을 일치 검증한다. 단순 접두어 변환이나 문자열 일치만으로 코드체계 추정 금지. 행정구역 변경·상위 시와 일반구·다대일/일대다 대응은 공간단위 일치 또는 검증된 집계 외에는 차단한다. 명칭만 있는 경우에도 완전한 상위지역·공간단위·시점·공식 경계가 유일하게 일치하는 경우에만 별도 검증·확인 경로를 허용한다. 미확인 비어 있지 않은 코드를 이름으로 우회하지 않는다.
4. 시도 및 시군구 모두 동일한 공통 resolver를 거치도록 하며, 기존 파서/수치 검사/검증 보고서/공간단위 차단/연습자료 기능을 보존한다. 원본코드와 지도코드를 따로 저장하고 대응 근거·출처·버전을 audit에 남긴다. 기존 PR #28의 실증과 통합 시 회귀 테스트를 유지한다.
5. 기존 UI: 지역/공간 단위 선택 → 원본 엑셀 넣기 → 결과 확인(매칭 수/누락/중복) → CSV 저장 및 e-GIS 열기. 간편 화면에서 세부 코드 노출 최소화, 하단 DETAIL에서 오류 원인 및 해결 안내. 오연결·미확인·중복·누락일 때 지도용 CSV 차단; 사용자 선택 범위의 명시적 표본은 전체 모집단으로 표시하지 않는다. 빈값을 0으로 대체하거나 비율을 단순 평균하지 않는다.
6. 기존 Worker/API나 신규 서버가 필요하지 않다. 인증/학생 데이터/공식 평가계획·제출 폼·권한은 변경하지 않는다. 원본 파일과 운영 main을 보존하고 별도 브랜치, Draft PR 방식으로 검토한다. 배포 승인 전 변경 없음.

### 완료 기준
- 기존 PR #28 39행 회귀 + 서울 25구 1인가구비율(DT_1YL21161/T10/2024) + 전국 17시도 합계출산율(DT_1B8000H/T12/2024) 실제 원본 XLSX부터 CSV까지 자동 변환, 전수 대조.
- 추가로 강원 시군, 경북 시군, 전국 시군구, 서로 다른 주제(경제/주거/보건 등)의 실제 KOSIS 원본과 연결. 통계표별 유효 공간단위 확인. 특히 일반구/상위 시, 동명 지역, 통계연도/경계연도 불일치, 개편 경계, 다중항목/다중연도, 합계/소계, 누락/중복, 결측/0에 대한 실패 테스트.
- 실제 e-GIS에서 경계 불러오기/테이블 결합/수치필드 지도 제작/저장·재열기/PDF·대표 이미지. 원본·CSV·지도 연결된 수치 전수 대조. 학교 Windows/iPad/모바일 실제 기기 확인(화면 크기 시뮬레이션과 구별). 기기·권한 문제는 교사 확인으로 남기며 학생 실데이터 제출은 금지.
- `테스트 대응 성공`은 자료 자체의 독립 검증이나 e-GIS 결합 성공이 아니다. 전체 학생 자유주제 지원 여부를 실제 성공/실패/미검증으로 구분하여 기록한다.

### 현재 한계
이 함수는 수치 및 파일 구조의 검증을 기존 앱에 위임한다. 공식 연계DB 원본은 아직 확보되지 않았다. 테스트 profile은 제한적이며 임의의 KOSIS 파일을 변환하지 못한다. 실제 브라우저 통합·원본 XLSX·e-GIS 결합·기기 검증·GitHub 쓰기/배포는 이번 작업에서 하지 않았다. 공식 레지스트리 기반 운영 기능을 완성하는 작업은 Codex에서 수행해야 한다.
