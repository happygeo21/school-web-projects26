인증키는 입력하지 않습니다. 공개 Worker 주소를 이용합니다. 교사용 화면 표시는 보안 인증이 아니므로 학생용 공개 사이트에서는 API 사용량 제한 또는 별도 접근 통제를 적용하세요.

2023년 9월 총인구는 예시입니다. 다른 통계표는 항목·분류 코드를 확인하세요.

API 응답은 현재 브라우저에서만 처리합니다. 항목 선택 전까지 원본 자료를 변경하지 않습니다.

파일 저장

학생은 보통 GIS 조인용 CSV면 충분합니다. 교사는 XLSX를 받으면 원본 전체·검증·기준표까지 함께 보관할 수 있습니다.

e-GIS 다음 단계
1 시군구 경계 레이어 불러오기
2 레이어 → 테이블 결합
3 가능하면 code ↔ code로 결합
4 결합 확인 후 단계구분도 만들기
공간자료에 code가 없고 name만 있다면 name ↔ name을 사용하세요.
수업 팁: 학생에게는 “KOSIS 파일 넣기 → 변환 → CSV 받기 → e-GIS에서 code로 결합” 네 단계만 안내해도 됩니다. 오류가 있을 때는 ‘확인 필요 행’에서 엑셀을 다시 열지 않고 바로 수정할 수 있습니다.

지역명 표준화
전북→전북특별자치도 같은 명칭 차이, 시도 문맥, 중구·동구 같은 중복명을 구분합니다.
일반구 복원
KOSIS 파일에 장안구·권선구처럼 하위 일반구가 실제로 있을 때만 수원시장안구처럼 안전하게 결합합니다. 상위 시 합계만 있는 자료는 억지로 252개에 복제하지 않고 경고합니다.
합계행 분리
전국·시도합계·동부·읍부·면부·상위 시 합계는 GIS 조인용에서 제외하고 전체 결과에는 보존합니다.
안전한 오류 처리
모호하거나 기준표에 없는 지역은 임의 매칭하지 않고 확인 필요로 남깁니다.
기본 기준: 2025년 252개 시군구. 행정구역이 개편되면 ‘교사용 고급 설정’에서 최신 시군구 속성 CSV를 넣어 갱신하세요. Excel 읽기·XLSX 저장은 SheetJS CDN을 사용하므로 인터넷이 끊긴 환경에서는 CSV/TXT 읽기와 CSV 저장을 우선 이용하세요.
