Firebase 보안 규칙 점검 안내

주의: 이 페이지는 자동으로 규칙을 변경하지 않습니다. 학급 접속 오류를 해결하려고 실시간 데이터베이스 전체 또는 활동 경로에 무조건적인 읽기·쓰기 권한을 허용해서는 안 됩니다.

교사용 Google/이메일 로그인과 학생 익명 로그인을 지원합니다. 최종 접근 권한은 Firebase Realtime Database Rules에서 검사해야 합니다.

안전한 점검 순서

  1. Firebase Console → Realtime Database → 규칙을 열고 현재 규칙을 안전한 곳에 백업합니다.
  2. 비로그인 사용자가 학생 데이터 경로를 읽거나 변경할 수 없는지 확인합니다.
  3. 로그인한 학생도 본인 UID 경로 이외의 자료를 읽거나 수정하지 못하도록 제한합니다.
  4. 교사 전체 조회·삭제·공개 승인 권한은 승인한 교사 계정으로만 제한합니다.
  5. Firebase Emulator Suite / Rules Playground를 이용해 무인증·학생·교사 권한을 각각 테스트한 후 게시합니다.
  6. 실제 학급 등록과 학생 제출을 시도하고, 교사가 아닌 로그인 계정의 전체 조회가 거부되는지 확인합니다.
