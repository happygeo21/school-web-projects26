## 재사용 원칙

- 이미지 요청이 열려 있을 때는 목적·대상·매체에 적합한 **서로 다른 후보 3~4개**와 **추천 1개**를 먼저 제안합니다. 스타일 키워드, 표현 특징, 적합한 활용, 비율을 한눈에 비교하게 설명합니다.
- **즉시 생성 또는 특정 스타일**을 요청했다면 불필요한 재확인 없이 곧바로 제작합니다.
- 실측 지도·정확한 통계·인터랙티브 HTML 같은 비이미지 자료에는 맞는 원본 데이터·코드·도구를 이용합니다.
- `/droneview` 등의 슬래시 키워드는 **ChatGPT의 공식 명령어가 아니며**, 스타일 이름표입니다.
- 학생 대상 교육 이미지에서는 위치·경계·수치·과학적 사실 검증을 우선합니다.
