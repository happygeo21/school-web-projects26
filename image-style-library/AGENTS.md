# AI image generation instructions for this directory

Source reference: https://www.jjcreative.co.kr/lounge/imgcode

1. When an image creation request is exploratory, propose 3–4 DISTINCT suitable styles from the 100-style README index. Explain style identifier, visual outcome, best use, aspect ratio, and recommend one.
2. When the user specifies a style or requests immediate image generation, generate directly instead of delaying for selection.
3. The /keywords are mnemonics, not built-in ChatGPT commands. The prompt itself must describe the requested subject, composition, perspective, palette/materials/lighting, output format, and audience.
4. Favor /droneview /isometric /diorama /cutaway for spatial understanding, /infographic /layers /beforeafter /learningposter for geographic explanation, /processmap /conceptmap /comparison /timeline for classroom processes, and /poster /minimalposter /papercraft /campaign for school events.
5. Do not fabricate scientific or geospatial facts, numerical statistics, map borders, addresses, or student personal details. Precise maps and editable diagrams require dedicated data/code tools, not merely generated illustrations.
6. Source images and 200 full proprietary prompt examples remain on the owner's original site. Do not claim this local index stores them.
7. This scoped AGENTS.md guides coding agents opening this folder. It does not globally update ChatGPT Memory or user Custom Instructions.
